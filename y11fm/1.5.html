Expanding Brackets

Expanding two brackets you can already do; the reason to be disciplined about the layout is that today it grows to a cubic times a quadratic, and that same column layout is what keeps the binomial expansion in 1.6 readable instead of a sprawl of terms.

By the end you’ll know…
  • Two linear brackets expand by multiplying each term in the first bracket by each term in the second (e.g. using a grid or FOIL), collecting like terms to give a quadratic ax² + bx + c.
  • A cubed bracket is expanded by building up from the squared bracket first: square the bracket, then multiply that result by the original bracket once more.

Learn

Read each card, then follow the worked examples one step at a time.

Every term by every term

Each term in one bracket multiplies each term in the other. Here (x - 3)(x - 5) gives four products: x² - 8x + 15.

A squared bracket

A squared bracket is the bracket times itself. So (x + 3)² = x² + 6x + 9, not x² + 9.

WORKED EXAMPLE A

Learn

Read each card, then follow the worked examples one step at a time.

Longer products

Every term still multiplies every term, however long the brackets. A grid shows (x + 3)(x² + 2x - 1) as six products.

A cubed bracket

A cubed bracket is squared first. The square is then multiplied by the bracket once more.

WORKED EXAMPLE C
Expand (x³ + 2x - 1)(x² - 3).One row for each term of the cubic, then collect like powers.
x^3 timesx⁵ - 3x³
2x times2x³ - 6x
-1 times-x² + 3
Collectx⁵ - x³ - x² - 6x + 3
WORKED EXAMPLE D
Expand (2x - 1)³.Square first, then multiply by (2x - 1) once more.
Square(2x - 1)² = 4x² - 4x + 1
Multiply(4x² - 4x + 1)(2x - 1) = 8x³ - 4x² - 8x² + 4x + 2x - 1
Collect8x³ - 12x² + 6x - 1
YOUR TURN · c
Expand (x + 2)(x² - 3x + 4).
x³ - 3x² + 4x + 2x² - 6x + 8 = x³ - x² - 2x + 8.
YOUR TURN · d
Expand (x + 3)³.
(x + 3)² = x² + 6x + 9, then (x² + 6x + 9)(x + 3) = x³ + 9x² + 27x + 27.
