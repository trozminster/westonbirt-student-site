Normals, Increasing and Decreasing

The normal is the line at right angles to a curve, and the sign of the gradient shows where a function climbs or falls. Both are quick consequences of being able to differentiate.

By the end you’ll know…
  • The normal is perpendicular to the tangent, so its gradient is the negative reciprocal.
  • A function is increasing where its derivative is positive and decreasing where it is negative.

At right angles to the tangent

The normal is perpendicular to the tangent at the point. Its gradient is the negative reciprocal of the tangent's.

Then the line

The normal's gradient goes into y - y1 = m(x - x1). Clearing the fraction gives ax + by + c = 0.

05

Learn

Read each card, then follow the worked examples one step at a time.

The sign of the gradient

A function is increasing where dydx > 0. It is decreasing where dydx < 0.

An inequality

Increasing means solving dydx > 0 as an inequality. A quadratic dydx needs a sketch of its sign.

WORKED EXAMPLE C
Find the values of x for which y = x² - 6x + 1 is increasing.Increasing means the gradient is positive.
Differentiatedydx = 2x - 6
Increasing2x - 6 > 0
x > 3
WORKED EXAMPLE D
Find the values of x for which y = x³ - 12x is decreasing.Sketch y = 3x² - 12: it is below the axis between its roots.
Differentiatedydx = 3x² - 12
Decreasing3x² - 12 < 0, so x² < 4
-2 < x < 2
YOUR TURN · c
Find the values of x for which y = 5 + 4x - x² is increasing.
dydx = 4 - 2x > 0, so x < 2.
YOUR TURN · d
Show that y = x³ + 3x is increasing for all values of x.
dydx = 3x² + 3. x² ≥ 0, so dydx ≥ 3 > 0 for every x.
