Trigonometric Identities

Two identities let any mix of sin, cos and tan be rewritten in a single function. That turns hard-looking trig equations into quadratics you already know how to solve.

By the end you’ll know…
  • Applying Pythagoras to the unit circle definition gives sin² x + cos² x = 1, and the same definitions give tan x = sin x ÷ cos x.
  • Both hold for any angle, not only acute ones.
By the end you can

Learn

Pythagoras on the unit circle

The point (cos θ, sin θ) lies on a circle of radius 1. Pythagoras then gives sin² θ + cos² θ = 1.

Tan from sin and cos

On the unit circle, tan θ is y ÷ x. So tan θ = sin θcos θ, for any angle.

One function only

Each identity swaps one function for another. So cos²x becomes 1 - sin²x, and sin xcos x becomes tan x.

WORKED EXAMPLE A
Show that cos²x - sin²x = 2cos²x - 1.
Work on the left-hand side only, and keep the bracket when sin²x is replaced.
Use sin²x = 1 - cos²x: cos²x - (1 - cos²x)
Remove the bracketcos²x - 1 + cos²x
= 2cos²x - 1
WORKED EXAMPLE B
Write tan x cos x1 - cos²x in terms of sin x.
One identity on top, the other underneath.
Toptan x cos x = (sin xcos x) × cos x = sin x
Bottom1 - cos²x = sin²x
sin xsin²x = 1sin x
YOUR TURN · a
Write 3 - 3sin²x in terms of cos x.
3 - 3sin²x = 3(1 - sin²x) = 3cos²x.
YOUR TURN · b
Simplify sin xtan x.
sin x ÷ (sin xcos x) = sin x × cos xsin x = cos x.

Learn

Read each card, then follow the worked examples one step at a time.

Into one function

A mixed equation is turned into one function with an identity. It is then often a quadratic.

Keep every root

A root outside -1 to 1 gives no angle. Factorising keeps the roots that dividing by cos x would lose.

WORKED EXAMPLE C
Solve 2cos²x - sin x - 1 = 0 for 0° ≤ x ≤ 360°.
Swap cos²x for 1 - sin²x, then it is a quadratic in sin x.
Use cos²x = 1 - sin²x: 2sin²x + sin x - 1 = 0
Factorise(2sin x - 1)(sin x + 1) = 0
sin x = 0.5 gives 30° and 150°
sin x = -1 gives 270°
WORKED EXAMPLE D
Solve 3 sin x = 4 cos x for 0° ≤ x ≤ 360°.
Dividing by cos x is safe hereif cos x = 0
then sin x = 0 too, which is impossible.
Divide by 3 cos xtan x = 43
Principal valuex = tan⁻¹ (4 ÷ 3) = 53.1°
Add 180°x = 233.1°
YOUR TURN · c
Solve 2sin²x = 1 + cos x for 0° ≤ x ≤ 360°.
2(1 - cos²x) = 1 + cos x, so 2cos²x + cos x - 1 = 0 and (2cos x - 1)(cos x + 1) = 0. So x = 60°, 180° or 300°.
YOUR TURN · d
Solve sin x cos x = 0.5 cos x for 0° ≤ x ≤ 360°.
cos x(sin x - 0.5) = 0. cos x = 0 gives 90° and 270°; sin x = 0.5 gives 30° and 150°.
