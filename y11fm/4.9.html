Limiting Value of a Sequence

Some sequences settle towards a value without ever reaching it, and being able to find that value and describe it with the right notation is the first step towards the ideas behind calculus in the next chapter.

By the end you’ll know…
  • As n tends to infinity, terms such as 1n tend to zero but never equal it.
  • Dividing numerator and denominator by the highest power of n reveals the limiting value.

Learn

Read each card, then follow the worked examples one step at a time.

1n tends to 0

As n grows, the terms of 1n get closer to 0
No term ever equals 0
So 1n tends to 0

As n gets larger the terms of 1n get smaller and closer to 0, but no term is ever equal to 0
We say 1n tends to 0, and we do not say it equals 0

Divide by n

Dividing top and bottom by the highest power of n finds the limit. Every term with n on the bottom then tends to 0

To find the limit of a fraction in n, divide the top and the bottom by the highest power of n. Every term with n on the bottom then tends to 0

The highest power

When the top and bottom both have n2, divide everything by n2
The limit is then the ratio of the n2 coefficients.

WORKED EXAMPLE A
Find the limiting value of un =3n+1n+2.
Dividing top and bottom by n makes the small terms into fractions that tend to 0
Divide top and bottom by nun =3+1n1+2n
As n grows, 1n and 2n tend to 0
So un tends to 3÷1=3
WORKED EXAMPLE B
Find the limiting value of un =2n2+1n2+3n.
The highest power is n2, so divide everything by n2
Divide by n2un =2+1n21+3n
As n grows, 1n2 and 3n tend to 0
So un tends to 2÷1=2

Learn

Read each card, then follow the worked examples one step at a time.

Correct notation

A limit is written with tends to, not with an equals sign. The terms get closer without ever arriving. Writing n = infinity is wrong too.

A limit is written with tends to, not with an equals sign, because the terms get closer without ever arriving. We also never write n = infinity, because infinity is not a number.

Proving a limit

A limit L is proved by showing the gap L - un tends to 0
The gap goes over one common denominator first.

To prove that un tends to L, show that the gap L−un is a fraction that tends to 0
Put the gap over one common denominator and simplify.
WORKED EXAMPLE C
Prove that un =3n+1n+2 tends to 3 as n tends to infinity.
Show that the gap between 3 and un tends to 0
Find the gap3−un=3(n+2)−(3n+1)n+2
Expand the top=3n+6−3n−1n+2
Simplify=5n+2
As n tends to infinity, 5n+2 tends to 0
So 3−un tends to 0, so un tends to 3
WORKED EXAMPLE D
Find the limit of un =4n−12n+3, then prove it.
Find the limit by dividing through, then prove it with the gap.
Divide by nun=4−1n2+3n
As n tends to infinityuntendsto42=2
Gap2−un=2(2n+3)−(4n−1)2n+3
Expand the top=4n+6−4n+12n+3
Simplify=72n+3
72n+3 tends to 0, which proves un tends to 2
