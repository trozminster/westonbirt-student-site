Piecewise Functions

Real situations such as taxi fares, tax bands and parking charges change their rule part-way along, and a piecewise function is how mathematics writes that down in one definition and draws it on one graph.

By the end you’ll know…
  • A function may be defined by different rules over different parts of its domain, with the sub-domains covering the whole domain without overlapping.

02

Learn

Read each card, then follow the worked examples one step at a time.

Sub-domains

A piecewise function uses a different rule on each part of its domain. The parts must cover every input once, with no overlap and no gap.

A piecewise function uses a different rule on each part of its domain, and the parts must cover every input once. They must not overlap, and they must not leave a gap.

Choosing the rule

Each input uses only the rule for its own sub-domain. So the domain is checked before anything is calculated.

To evaluate, first find which sub-domain the input belongs to, and then use only that rule. For f(x) = x + 2 when x ≤ 1 and f(x) = 4 - x when x > 1, the input 0 uses the first rule and the input 3 uses the second.

Drawing it

Each rule is drawn only over its own sub-domain. Here the two pieces meet at (1, 3).

To draw a piecewise function, draw each rule only over its own sub-domain and join the pieces where they meet. Here the two lines meet at (1, 3).
WORKED EXAMPLE A
Given f(x) = 2x + 1 for x ≤ 3 and f(x) = 10 - x for x > 3, find f(1), f(3) and f(5).Check the sub-domain for each input before using a rule.
f(1)1 ≤ 3, so use 2x + 1: f(1) = 3
f(3)3 ≤ 3, so use 2x + 1: f(3) = 7
f(5)5 > 3, so use 10 - x: f(5) = 5
WORKED EXAMPLE B
Draw y = f(x) for -1 ≤ x ≤ 5 where f(x) = x for x ≤ 2 and f(x) = 4 - x for x > 2.Each rule is drawn only over its own part of the x-axis.
Piece 1 on x ≤ 2y = x, from (-1, -1) to (2, 2)
Piece 2 on x > 2y = 4 - x, from (2, 2) to (5, -1)
The pieces meet at (2, 2), so there is no jump

f(x) = x² for x < 0 and f(x) = 2x + 1 for x ≥ 0. Find f(-3) and f(0).
-3 < 0, so use x²: f(-3) = 9. 0 ≥ 0, so use 2x + 1: f(0) = 1.
YOUR TURN · b

Learn

Reading pieces from a graph

A definition from a graph needs each piece's gradient and intercept. It also needs the x-values where the pieces change.

To write a definition from a graph, find the gradient and intercept of each piece and the x-values where the pieces change. This graph has three straight pieces, one rising, one flat and one falling.

The range

The range of a piecewise function is every output from all the pieces together. For the graph above the lowest output is 0 and the highest is 4.

In context

A real charge often changes rule at a boundary. Here the second rule is 3 + 2(d - 2).

A real charge often changes rule at a boundary, such as a fixed fee up to some distance and then a rate per extra kilometre. For a taxi charging £3 up to 2 km and then £2 per extra km, the second rule is 3 + 2(d - 2).
WORKED EXAMPLE C
A graph is a line from (0, 1) to (2, 5) and then a line from (2, 5) to (4, 1). Write f(x) as a piecewise function.Each piece needs its own gradient, and the pieces must agree where they meet.
First line, gradient (5 - 1) ÷ 2 = 2, intercept 1: y = 2x + 1 for 0 ≤ x ≤ 2
Second line, gradient (1 - 5) ÷ 2 = -2, through (4, 1): y = 9 - 2x for 2 < x ≤ 4
Check at x = 2: 2(2) + 1 = 5 and 9 - 4 = 5
WORKED EXAMPLE D
A taxi charges £3 for the first 2 km and then £2 per extra km. Write the cost C for a journey of d km.The second rule counts only the distance beyond 2 km.
For 0 < d ≤ 2 the cost is flatC = 3
For d > 2 the extra distance is d - 2 at £2 each: C = 3 + 2(d - 2)
SimplifyC = 2d - 1 for d > 2
YOUR TURN · c
A graph is flat at y = 3 from x = 0 to x = 2, then a line from (2, 3) to (5, 0). Write it as a piecewise function.
y = 3 for 0 ≤ x ≤ 2. The gradient is 0 - 35 - 2 = -1, so y = 5 - x for 2 < x ≤ 5.
YOUR TURN · d
State the range of f(x) = x + 1 for 0 ≤ x ≤ 2 and f(x) = 3 for 2 < x ≤ 5.
The first piece gives outputs from 1 to 3 and the second gives 3. The range is 1 ≤ f(x) ≤ 3.
