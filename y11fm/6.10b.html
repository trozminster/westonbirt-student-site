Solving Trigonometric Equations

A trig equation's answers come back every period, so the whole skill is a reliable method that catches every one inside the stated range. Most exam equations also need tidying up before that method can start.

By the end you’ll know…
  • A systematic method finds all solutions in a range: find the principal value from the calculator, use the graph's symmetry to find a second value in the range (180 - principal value for sine, 360 - principal value or its negative for cosine, principal value + 180 for tangent), then add or subtract whole periods to bring every solution into the required range.

02

Learn

Read each card, then follow the worked examples one step at a time.

The method

The method starts with the principal value and a second value by symmetry. Adding or subtracting whole periods then fills the range.

The second value

For sine, the second value is 180° minus the principal value. For cosine, it is 360° minus it. For tangent, it is plus 180°.

WORKED EXAMPLE A
Solve sin x = 0.3 for -360° ≤ x ≤ 360°.
Two values from the method, then subtract 360° from each to reach below zero.
Principal valuex = sin⁻¹ (0.3) = 17.5°
Second valuex = 180 - 17.5
= 162.5°
Subtract 360°x = -342.5°
x = -197.5°
x = -342.5°, -197.5°, 17.5°, 162.5°
WORKED EXAMPLE B
Solve cos x = -0.4 for 0° ≤ x ≤ 720°.
The range is two full turns, so add 360° to each of the first two values.
Principal valuex = cos⁻¹ (-0.4) = 113.6°
Second valuex = 360 - 113.6
= 246.4°
Add 360°x = 473.6°
x = 606.4°
x = 113.6°, 246.4°, 473.6°, 606.4°
YOUR TURN · a
Solve tan x = 3 for -180° ≤ x ≤ 360°.
The principal value is tan⁻¹ (3) = 71.6°. Tan repeats every 180°, so x = -108.4°, 71.6° or 251.6°.
YOUR TURN · b
Solve sin x = -0.3 for 0° ≤ x ≤ 360°.
The principal value is -17.5°, outside the range. The second value is 180 - (-17.5) = 197.5°, and -17.5 + 360 = 342.5°. So x = 197.5° or 342.5°.

05

Learn

Read each card, then follow the worked examples one step at a time.

Rearrange first

The trig function is made the subject before any inverse is taken. So 2 sin x + 1 = 0 becomes sin x = -0.5 first.

A multiple angle

For tan 2x = k, the range for 2x is double the range for x. Every value of 2x is found first, then halved.

WORKED EXAMPLE C
Solve 5 cos x - 2 = 0 for 0° ≤ x ≤ 360°.
Make cos x the subject before any inverse is used.
Add 2 and divide by 5cos x = 0.4
Principal valuex = cos⁻¹ (0.4) = 66.4°
Second valuex = 360 - 66.4
= 293.6°
WORKED EXAMPLE D
Solve tan 2x = 1 for 0° ≤ x ≤ 360°.
2x runs from 0° to 720°, and tan repeats every 180°.
Range for 2x0° ≤ 2x ≤ 720°
Every 2x2x = 45°, 225°, 405°, 585°
Halvex = 22.5°, 112.5°, 202.5°, 292.5°
YOUR TURN · c
Solve 3 tan x + 4 = 0 for 0° ≤ x ≤ 360°.
tan x = -43, so the principal value is -53.1°. Adding 180° gives 126.9°, and adding 360° gives 306.9°. So x = 126.9° or 306.9°.
YOUR TURN · d
Solve cos 2x = 0.5 for 0° ≤ x ≤ 180°.
The range for 2x is 0° to 360°, so 2x = 60° or 300°. So x = 30° or 150°.
