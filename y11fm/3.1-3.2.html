Functions, Domain and Range

Every formula that turns one number into another is a function, and knowing exactly which inputs it accepts and which outputs it gives is what makes composing, inverting and graphing safe to do for the rest of this chapter.

By the end you’ll know…
  • A function assigns exactly one output to each input.
  • The domain is the set of permitted inputs and the range the set of outputs it produces, so excluded values such as division by zero restrict the domain.

One output for each input

A function gives exactly one output for every input. An input with two outputs means it is not a function.

A function gives exactly one output for every input, so the same input can never lead to two different outputs. A table that sends one input to two outputs is not a function.

Evaluating and solving

The notation f(3) means the rule applied to the input 3
Solving f(x)=9 runs the rule backwards, from output to input.

The notation f(x) names the rule, so f(3) means apply the rule to 3, and solving f(x)=k runs the rule backwards from a known output. One finds an output from an input, the other finds an input from an output.

Substitute x=−2: f(−2)=3×(−2)−2=−8

Learn

Read each card, then follow the worked examples one step at a time.

Domain and range

The domain is the inputs, read on the x-axis. The range is the outputs, read on the y-axis.

The domain is the set of inputs a function accepts and the range is the set of outputs it gives, so on a graph the x-values give the domain and the y-values give the range. A curve that never goes below a line has a range that stops at that line.

Excluded inputs

A function is not defined where its rule breaks. Inputs that divide by zero or root a negative leave the domain.

A function is not defined where its rule breaks, such as dividing by zero or taking the square root of a negative number, so those inputs are left out of the domain. The values that break the rule are found by asking what makes the denominator zero or the root negative.
