Factorising Polynomials Fully

A first factor is only the start, and the work of fully factorising a cubic, including ones with a leading coefficient above 1, is what turns the factor theorem into a way of solving polynomial equations.

By the end you’ll know…
  • Once one factor is known, the remaining quadratic factor is found by division or by comparing coefficients, and the leading coefficient must be accounted for so the two factors multiply back to the original polynomial.
  • The extended factor theorem states that if f(ab) = 0 then (bx - a) is a factor of f(x), so candidates for a non-unit leading coefficient are found among factors of the constant term over factors of the leading coefficient.

Finding the quadratic factor

A known linear factor leaves a quadratic factor to find. Comparing coefficients finds it: the constant term first, then x².

Once (x - a) is known, write the cubic as (x - a) multiplied by x² + px + q, and compare coefficients. The constant term fixes q, and the x² terms then fix p.

Factorise fully

The quadratic factor may factorise again. The job is done only when every factor is linear.

The quadratic factor may itself factorise, and the job is not done until every factor is linear. Check the quadratic before you stop.
WORKED EXAMPLE A
Given that (x - 1) is a factor, fully factorise f(x) = x³ - 6x² + 11x - 6.Compare the constant first, then the x² terms.
Write (x - 1)(x^2 + ax + b)the constant gives -b = -6
b = 6
The x² terms give a - 1 = -6, so a = -5
Factorise x^2 - 5x + 6f(x) = (x - 1)(x - 2)(x - 3)
WORKED EXAMPLE B
Given that (x + 2) is a factor, fully factorise f(x) = x³ + 5x² + 2x - 8.The constant of (x + 2) is positive, so the signs change.
Write (x + 2)(x^2 + ax + b)the constant gives 2b = -8
b = -4
The x² terms give a + 2 = 5, so a = 3
Factorise x^2 + 3x - 4f(x) = (x + 2)(x + 4)(x - 1)
YOUR TURN · a
Given that (x - 2) is a factor, fully factorise x³ - 7x + 6.
-2b = 6 gives b = -3, and a - 2 = 0 gives a = 2. x² + 2x - 3 = (x + 3)(x - 1), so f(x) = (x - 2)(x + 3)(x - 1).
YOUR TURN · b
Given that (x + 1) is a factor, fully factorise x³ + 2x² - x - 2.
b = -2 from the constant, and a + 1 = 2 gives a = 1. x² + x - 2 = (x + 2)(x - 1), so f(x) = (x + 1)(x + 2)(x - 1).

The extended factor theorem

With a leading coefficient other than 1, a root may be a fraction ab. Then (bx - a) is the factor. Candidates are constant factors over leading-coefficient factors.

When the leading coefficient is not 1, a root may be a fraction ab, and then (bx - a) is the factor. Candidates are the factors of the constant over the factors of the leading coefficient.

Solving by factorising

A fully factorised polynomial gives one root per bracket. A bracket with a coefficient gives a fraction.

Once a polynomial is fully factorised, each bracket is set to zero in turn, which gives every root. A bracket with a coefficient gives a fraction.
WORKED EXAMPLE C
Show that (2x - 1) is a factor of f(x) = 2x³ + 3x² - 8x + 3.2x - 1 is zero at x = 12, so test f(12).
2x - 1 = 0 when x = 12, so find f(12)
f(12) = 2(18) + 3(14) - 8(12) + 3 = 14 + 34 - 4 + 3
f(1 ÷ 2) = 0, so (2x - 1) is a factor
WORKED EXAMPLE D
Solve x³ - 2x² - 5x + 6 = 0.Find a factor, factorise fully, and then set each bracket to zero.
f(1) = 1 - 2 - 5 + 6 = 0, so (x - 1) is a factor
Divide(x - 1)(x² - x - 6) = (x - 1)(x - 3)(x + 2)
Solve each bracketx = 1
x = 3
or x = -2
YOUR TURN · c
Show that (2x + 1) is a factor of f(x) = 2x³ - x² - 5x - 2.
f(-12) = -14 - 14 + 52 - 2 = 0, so (2x + 1) is a factor.
YOUR TURN · d
Solve x³ - 3x² - 4x + 12 = 0.
f(2) = 8 - 12 - 8 + 12 = 0, so (x - 2) is a factor. The quadratic is x² - x - 6 = (x - 3)(x + 2), so x = 2, 3 or -2.
