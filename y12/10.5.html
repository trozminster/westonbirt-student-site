Harder Trigonometric Equations

Exam equations rarely ask for sinx=k directly: they ask for sin2x=k or cos(x−30°) =k. Writing X for the angle turns each into last lesson's equation, provided the interval changes with it.

By the end you’ll know…
  • To solve sin(2x)=k, let X=2x, change the interval to match, solve for X, then divide by 2
  • If 0°≤x≤360°, then 0°≤2x≤720°, so there are twice as many solutions.
  • An equation such as cos(x−30°)=k is solved in the same way, with the interval shifted by 30°.

02

Learn

Read each card, then follow the worked examples one step at a time.

A multiple of x squeezes the graph

The graph of y=sin2x repeats every 180°, so it fits two waves into 0° to 360°. So sin2x=k has twice as many solutions as sinx=k.

The interval changes with the angle

When x runs from 0° to 360°, 2x runs from 0° to 720°. Every solution for 2x in that range gives one for x.

WORKED EXAMPLE A
Solve sin2x=0.6 for 0°≤x≤360°.
Let X=2x. Solve sinX=0.6 for 0°≤X≤720°, then halve.
Change the interval0°≤2x≤720°
Solve for 2x2x=36.9°, 143.1°, 396.9°, 503.1°
Divide by 2x=18.4°, 71.6°, 198.4°, 251.6°
WORKED EXAMPLE B
Solve tan3x=1 for 0°≤x≤180°.
Let X=3x. tan repeats every 180°, so add 180° until X passes 540°.
Change the interval0°≤3x≤540°
Solve for 3x3x=45°, 225°, 405°
Divide by 3x=15°, 75°, 135°

05

Learn

Read each card, then follow the worked examples one step at a time.

A shift moves the interval

When x runs from 0° to 360°, x−30° runs from −30° to 330°. The whole interval shifts by the same amount as the angle.

Check both ends of the new interval

A solution for the shifted angle can now be below 0° or above 360°. Keep every value inside the new interval and no others.

WORKED EXAMPLE C
Solve sin(x+60°)=0.7 for 0°≤x≤360°.
Let X=x+60°. The new interval runs to 420°, so 360°+44.4° is inside it.
Change the interval60°≤x +60°≤420°
Solvex+60°=135.6°, 404.4°
Subtract 60°x=75.6°, 344.4°
WORKED EXAMPLE D
Solve sin(x−30°) =−0.4 for 0°≤x≤360°.
Let X=x−30°. The principal value −23.6° is inside the new interval, but 336.4° is not.
Change the interval−30°≤x −30°≤330°
Solvex−30°=−23.6°, 203.6°
Add 30°x=6.4°, 233.6°

Hint. Follow the worked example: Change the interval → Solve → Subtract 60°
−20°≤x −20°≤340°.x −20° =60° or 300°, so x=80° or 320°
YOUR TURN · d
