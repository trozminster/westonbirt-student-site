Vectors and Representing Vectors

A vector carries a size and a direction, and from Mechanics chapter 8 on it describes displacement, velocity and force. This lesson sets up the two ways to write one, i, j form and the column vector, and the parallel test that the proofs in 11.5 depend on.

By the end you’ll know…
  • A vector has a magnitude and a direction; a scalar has a magnitude only.
  • Vectors are added by the triangle law, one after the other, and −a has the same magnitude as a but the opposite direction.
  • The vector λa is parallel to a, so any vector parallel to a can be written λa.
  • The unit vectors 𝐢 and 𝐣 point along the x-axis and the y-axis, so a vector such as 3𝐢+4𝐣 can also be written as a column vector.
By the end you can
Add and subtract vectors and multiply them by a scalar, drawing the triangle law.
Show that two vectors are parallel, or find an unknown so that they are, by writing one as a multiple of the other.
Write a vector in i, j form and as a column vector, and add, subtract and scale vectors in both forms.

02

Learn

Read each card, then follow the worked examples one step at a time.

Head to tail

Vectors add by the triangle law: the second starts where the first ends. So a+b is the single step from the start of a to the end of b.

Back along an arrow is minus

−a has the same length as a and points the other way. So a−b is a+(−b): go along a, then back along b.

i and j

The unit vectors 𝐢 and 𝐣 point one unit across and one unit straight up. So 3𝐢+2𝐣 is 3 across and 2 up, the column vector (32).

05

Learn

Read each card, then follow the worked examples one step at a time.

Parallel means a multiple

λa is parallel to a. It points the same way when λ is positive and the opposite way when λ is negative.

One multiplier for both parts

6𝐢−9𝐣 =3(2𝐢−3𝐣), so 6𝐢−9𝐣 is parallel to 2𝐢−3𝐣. The same multiplier must work for the i part and the j part.

WORKED EXAMPLE C
Show that 6𝐢−9𝐣 is parallel to 4𝐢−6𝐣.
Find one multiplier for both parts.
Compare the i parts6=1.5×4
Compare the j parts−9=1.5×(−6)
6𝐢−9𝐣 =1.5(4𝐢−6𝐣), so parallel
WORKED EXAMPLE D
6𝐢+k𝐣 is parallel to 2𝐢−5𝐣. Find k.
The i parts give the multiplier.
Multiplier from the i parts6=3×2
Apply it to the j partsk=3×(−5)
k=−15
