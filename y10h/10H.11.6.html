Upper and Lower Bounds

A length given as 24 cm could really be anything from 23.5 cm up to 24.5 cm. Bounds say exactly how far a rounded value can be trusted.

By the end you’ll know…
  • A rounded value stands for an interval of possible true values, not a single one.
  • The bounds lie half a rounding unit either side, so 24 to the nearest whole number has bounds 23.5 and 24.5
  • The lower bound is included and the upper bound excluded, since 24.5 would itself round up.
  • The interval is written as an error interval in inequality notation: 23.5≤x<24.5
  • The rounding unit sets the half: to the nearest 10 the bounds are 5 either side, and to 1 decimal place 0.05

A rounded value is an interval

A rounded value stands for a whole interval. Its bounds lie half a unit either side.

A rounded value stands for every value that rounds to it. The bounds lie half a rounding unit either side of it.

Find the unit, then halve it

The unit is what the value was rounded to. Half of that unit gives the bounds.

The rounding unit is what the value was rounded to: the nearest 10, a decimal place or a significant figure. Half of that unit gives the bounds.

Learn

One end in, one end out

The lower bound is in the interval, and the upper bound is not. The upper bound rounds up.

The lower bound belongs to the interval, but the upper bound does not. The upper bound itself rounds up to the next value.

Written as an inequality

An error interval is written lower bound ≤ x < upper bound. For 24: 23.5≤x<24.5

An error interval is written lower bound ≤ x < upper bound. So 24 to the nearest whole number gives 23.5≤x<24.5
