General Fractional Indices

A power like 8⁽²³⁾ joins the last two lessons: a root and a power at once. Add a minus sign and the reciprocal joins in too - three steps, each one already known.

By the end you’ll know…
  • A power of mn is a root and a power: a⁽ᵐⁿ⁾ is the nth root of a, raised to the power m, which is also the nth root of aᵐ.
  • Taking the root first keeps the numbers small: 8⁽²³⁾ = 2² = 4.
  • A negative fractional index adds a reciprocal: a⁽⁻ᵐⁿ⁾ = 1a⁽ᵐ/ⁿ⁾, so 8⁽⁻²³⁾ = 14; the minus sign never makes the value negative.
  • A fraction base with a negative index is turned over first: (278)⁽⁻²/³⁾ = (827)⁽²/³⁾ = 49.

A root and a power

The denominator of the index is a root and the numerator is a power. So 8⁽²³⁾ is the cube root of 8, squared.

In an index mn, the denominator n is a root and the numerator m is a power. So 8⁽²³⁾ is the cube root of 8, which is 2, squared, which is 4.

Root first keeps numbers small

The two steps give the same answer in either order. Taking the root first keeps the numbers small.

The root and the power can be taken in either order and give the same answer. Taking the root first keeps the numbers small enough to work without a calculator.

A minus sign adds a reciprocal

A negative fractional index is a reciprocal, a root and a power. The minus sign never makes the answer negative.

A negative fractional index is three steps: a reciprocal, a root and a power. The minus sign only turns the value over, so the answer is never negative: 8⁽−²³⁾ is 14.

A fraction base turns over first

With a fraction base, the reciprocal turns the fraction over. Then the root and the power act on top and bottom.

With a fraction as the base, the reciprocal simply turns the fraction over. The root and the power then act on its top and its bottom, as before.
