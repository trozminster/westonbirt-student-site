Set Notation

Sets are how mathematics groups things: the even numbers, the people who play an instrument, the outcomes of a dice roll. A few symbols say exactly what is in a group, what is left out and what two groups share.

By the end you’ll know…
  • A set is a collection of distinct elements, named with a capital letter and listed in curly brackets: A={2,4,6}; order does not matter and nothing is listed twice.
  • 'x is an element of A' and 'x is not an element of A' are written with their own symbols; the universal set ξ holds every element under consideration, and the empty set holds none.
  • The complement A' is every element of ξ not in A, and n(A) is the number of elements in A.
  • A ∪ B is every element in A, in B or in both; A ∩ B is every element in both.
  • A is a subset of B when every element of A is also in B.
  • A set can be defined by a rule: {x : x is a prime number, x<10}={2, 3, 5, 7}.

Belonging

A set is a list of distinct elements in curly brackets. The symbol ∈ means 'is an element of'.

Complement and count

A' is everything in ξ that is not in A.n(A) counts the elements of A.

Union and intersection

A ∪ B holds everything in A or B or both. A ∩ B holds only what is in both.

Every element inside
