Adjusting, Adding and Subtracting in Standard Form

A phone holds 3.2×109 bytes of video and 4.5×108 bytes of music. Finding the total is column addition in disguise: the digits must line up by place value first.

By the end you’ll know…
  • A number is in standard form when it is written as A×10n, where 1≤A<10 and n is an integer.
  • Moving the decimal point of A one place left raises n by one, and one place right lowers it by one, so the value is unchanged: 34×105=3.4×106 and 0.62×10−3=6.2×10−4
  • Only numbers with the same power of 10 can be added or subtracted directly, because only matching place values combine: 4.2×105+3×104=4.2×105+0.3×105=4.5×105
  • The powers of 10 are never added when the numbers are added; the answer is rewritten if A has left 1≤A<10

Point left, power up

Moving the point left makes A smaller, so the power goes up. Moving it right makes A bigger, so the power goes down.

Match the powers first

Only digits of the same place value combine. So the powers of 10 must match before adding.

Digits combine only when they have the same place value, as in column addition. So two numbers in standard form are added only once they share a power of 10

The power is not added

Adding the numbers never adds their powers. The answer is rewritten if A leaves 1 to 10

Adding the numbers never adds their powers of 10: the power only says what each digit is worth. The answer is rewritten only if A has left the range 1 to 10
