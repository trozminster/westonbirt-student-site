Averages from Grouped Data

A table of marks in groups of ten hides every individual mark, yet we still want to know the typical one. Today we get as close as grouped data allows, and say honestly how close that is.

By the end you’ll know…
  • Grouping data loses the individual values, so only the class each value fell into is known.
  • The mean can therefore only be estimated, using the midpoint of each class to stand in for its values.
  • The estimated mean is the total of midpoint × frequency, divided by the total frequency.
  • The modal class is the class with the highest frequency, and the median is reported as the class containing the middle value.
  • Both answers are classes rather than single values, which is why they are named rather than calculated.

The midpoint stands in

Each class midpoint stands in for every value in it. For 10−19 it is (10+19)÷2=14.5
Midpoint × frequency estimates each class's total.

The midpoint of each class stands in for every value in it: for 10−19 it is (10+19)÷2=14.5
Midpoint × frequency then estimates each class's total.

Only an estimate

The estimated mean is the total of midpoint × frequency divided by the total frequency. It is an estimate, because the true values in each class are unknown.
