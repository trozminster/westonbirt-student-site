Topic 8.10 · Changing the Subject · Lesson 1 of 5

Changing the Subject

A formula is written to give one quantity, but a scientist or an engineer often needs a different one. Changing the subject turns the same formula round so that it gives whichever quantity you need.

By the end you’ll know…
  • Changing the subject rearranges a formula so that a different variable stands alone on one side.
  • It applies the same inverse operations to both sides as solving an equation does.
  • The operations are undone in the reverse of the order they were applied to the wanted subject.
  • The result is a formula rather than a number, so it answers for any set of values.

One formula, many subjects

The subject of a formula is the variable standing alone on one side. Changing the subject rewrites the same relationship so that a different variable stands alone.

The same moves as solving

Free the variable with inverse operations on both sides, as in solving. The result is a formula, not a number.

The wanted variable is freed by applying the inverse operation to both sides, just as in solving an equation. The result is a formula, not a number, so it works for any values.

05

Learn

Read each card, then follow the worked examples one step at a time.

Rearrange, then substitute

If the formula gives the wrong variable, rearrange it first. Then substitute the known values.

When a formula gives the wrong variable, rearrange it first and then substitute the known values. The rearranged formula can be reused for every new set of values.

Two routes, one answer

Substituting first leaves an equation to solve, while rearranging first leaves a single calculation. Both routes give the same value.

WORKED EXAMPLE C

Rearrangew=Al
Substitutew=36÷4.5
w=8
