Dividing into a Ratio

Splitting a £60 restaurant bill 2:3:1 between three friends, or sharing profits between business partners in proportion to what they invested - both need you to divide a total (or work backwards from a partial share) using a ratio. Today you learn both directions.

By the end you’ll know…
  • A ratio can be read additively, as a total number of equal parts to be shared out.
  • It can also be read multiplicatively, as each share being a fixed fraction of the total.
  • The additive view solves problems where the total is known: the total divided by the number of parts gives the value of one part.
  • The multiplicative view solves problems where only one share, or the difference between shares, is given.
  • In the ratio a:b the difference between the shares is (a−b) parts, which gives the value of one part directly.
By the end you can
G4Divide a quantity into a given ratio with two or three parts.
G5Solve problems where the difference between shares, or the value of one share, is given rather than the total, using the multiplier between shares.

The additive view

Add the parts of the ratio to get the total number of parts. Divide the whole amount by that total to find ONE part.

A ratio can be read as a total number of EQUAL PARTS to be shared out. Adding the parts of the ratio together gives the total number of parts; dividing the whole amount by that total gives the value of ONE part.

Sharing into 2 or 3 parts

Multiply one part's value by each share's number of parts. Check the shares add back to the total. Here £70 is shared 2 : 5

Once the value of one part is known, multiply it by each share's own number of parts to find that share's actual amount. Always check the shares add back up to the original total.
SHARING AN AMOUNT

Add the parts3+4+5=12
Divide by 12£84÷12=£7(the value of one part)
Multiply by 33×£7=£21
Multiply by 44×£7=£28
Multiply by 55×£7=£35
Check21+28+35=84

The multiplicative view

Given only ONE share, divide it by its own number of parts. That gives one part, with no total needed.

When only ONE share's value is given (not the total), that share IS a known multiple of one part - divide it by its own number of parts to find the value of one part directly, without ever needing the total.

Using the difference

In a:b, the difference between the shares is a−b parts. Divide the difference in value by a−b to find one part.

In the ratio a:b, the DIFFERENCE between the shares is (a−b) parts. If the actual difference in value between the two shares is given, dividing it by (a−b) gives the value of one part directly - just as dividing one share by its own number of parts does.
GIVEN ONE SHARE
Two amounts are in the ratio 3:7
The smaller amount is £24
Find the larger amount.
£24 is the smaller amount, so it is 3 parts- the smaller share's own number of parts
Divide by 3£24÷3=£8(the value of one part)
Multiply by 77×£8=£56(the larger amount)
YOUR TURN · c
Two amounts are in the ratio 1:4 and the smaller is £15, so find the larger.
£15 is 1 part, so one part is £15 and the larger amount is 4×£15=£60
YOUR TURN · d
Two amounts are in the ratio 2:9
The smaller amount is £30
Find the larger amount. (Hint: which number of parts does £30 correspond to?)
£30 is 2 parts, so one part is £15 and the larger amount is 9×£15=£135
