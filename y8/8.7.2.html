Venn Diagrams

Last lesson you wrote sets with curly-bracket notation. Today you draw them as pictures instead – the same Venn diagram you already used for HCF and LCM, now built properly from the notation you've just learned.

By the end you’ll know…
  • In a Venn diagram each set is a closed region inside a rectangle representing the universal set.
  • Every element appears exactly once, in the region matching all the sets it belongs to.
  • Elements in none of the sets sit inside the rectangle but outside every circle.
  • Two sets create four regions and three sets create eight, each region corresponding to one set expression.
  • An Euler diagram is used instead when the sets are nested or share no elements.

The structure

In a Venn diagram, the rectangle is the universal set ξ. Each element appears once, in the region matching every set it belongs to.

in a Venn diagram, the rectangle represents the universal set ξ, and each set is a closed region (usually a circle) inside it. Every element of ξ appears exactly once, in whichever region matches every set it belongs to – found by checking it against each set's condition in turn, never by guessing from the space available.

Regions

An element in both sets sits in the overlap. An element in neither sits outside every circle, inside the rectangle.

an element in both sets sits in the overlap; an element in neither set sits inside the rectangle but outside every circle. Two sets create four regions in total (A-only, B-only, overlap, neither); three sets create eight.

Union

A ∪ B means everything in A, in B, or in both. Shade the whole of both circles, overlap included.

A ∪ B(A ∪ B) means everything in A, or in B, or in both – to shade it, shade the whole of both circles, including the overlap.

Intersection

A ∩ B means everything in both A and B. Shade only the overlap: no more, no less.

A ∩ B(A ∩ B) means everything in both A and B – to shade it, shade only the overlapping region, leaving A-only and B-only unshaded. Always shade exactly what the definition covers – no more, no less.
SHADING A UNION
Shade A ∪ B on a two-set Venn diagram.
A ∪ B means "in A, or in B, or in both" – every element that belongs to at least one of the two sets.
Shade the whole of circle A, the whole of circle B, and the overlap between them. Only the region outside both circles is left unshaded.
