Probability from Venn Diagrams

The last two lessons were about identifying and shading the right region – today that skill pays off directly, because once you can identify a region correctly, its probability is just a count divided by a total.

By the end you’ll know…
  • A probability read from a Venn diagram is the number of elements in the region divided by n(ξ).
  • The region is identified from the set notation first, and its elements counted second.
  • Because every element appears exactly once, the region counts add up to n(ξ).
  • A given probability works backwards: multiplying it by n(ξ) gives the number of elements in that region.

The rule

P(region) = its number of elements ÷ n(ξ). Never divide by any other total in the diagram.

the probability of landing in a region equals the number of elements in that region divided by n(ξ), the total number of elements in the universal set – never by any other total in the diagram.

Method

Name the region from its notation first. Then count its elements, then divide by n(ξ).

identify the region from its set notation first (using what you learned shading compound regions), then count its elements second, then divide by n(ξ).
PROBABILITY FROM A VENN
ξ = {1,2,...,10}. A = {2,4,6,8,10}. B = {4,8}. Find P(A ∩ B) and P(A').
Find the overlapA ∩ B = {4, 8} (identify the region first)
Count over n(ξ)P(A ∩ B) = 210
Simplify= 15
Find the complementA' = {1, 3, 5, 7, 9} (identify the region first: everything not in A)
Count over n(ξ)P(A') = 510
Simplify= 12

Learn

From a probability back to a count

Multiply a region's probability by n(ξ) to recover its count. Use the whole fraction, not just one part of it.

because a region's probability is its element count divided by n(ξ), multiplying that probability by n(ξ) recovers the count – using the whole fraction, not just its numerator or denominator on its own.

Missing values

All the region counts add up to n(ξ): here, 22. Set up that total to find the missing count. Check your answer fits the total.

because every element appears exactly once, all the region counts in a Venn diagram must add up to n(ξ). If one region's count is unknown, set up that total (using every known region, plus any given probability) to solve for it, and check your answer actually satisfies the total.
PROBABILITY TO A COUNT
ξ has 20 elements. P(A) = 25. Find n(A).
Multiply P(A) by n(ξ)n(A) = 25 × 20 (a probability works backwards by multiplying by n(ξ))
= 8
Check820 = 25. Correct.
AN UNKNOWN REGION
A Venn diagram has n(ξ) = 20. The four regions are: A-only = 5, overlap = x, B-only = 7, neither = 4. Find x.
