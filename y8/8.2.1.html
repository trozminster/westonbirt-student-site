Inequalities on a Number Line

Speed limits, minimum ages, weight limits on a lift - real life is full of rules describing a whole range of allowed values, not just one number. Today you learn to read and draw these ranges as inequalities on a number line.

By the end you’ll know…
  • The symbols compare quantities: < is less than, > is greater than, <= is less than or equal to, >= is greater than or equal to.
  • An inequality describes a range of values, not a single one.
  • On a number line an open circle excludes the value and a filled circle includes it.
  • An arrow shows the range continuing without end.

Learn

Read each card, then follow the worked examples one step at a time.

The four symbols

< less than, > greater than. ≤ less than or equal to, ≥ greater than or equal to. Each describes a range: x < 5 means every number below 5.

< means less than, > means greater than, ≤ means less than or equal to, ≥ means greater than or equal to. Each symbol describes a whole range of values, not a single one - x < 5 means every number below 5, not just one number.

Circles

An open circle means the value is NOT included: used for < and >. A filled circle means it IS included: used for ≤ and ≥.

an open circle on a number line means the marked value is NOT included (used for < and >). A filled circle means the value IS included (used for ≤ and ≥).

Arrows

The arrow always points away from the circle. It points right for 'greater than', left for 'less than'.

the arrow always points away from the circle, continuing in the direction the range never ends - right for 'greater than', left for 'less than'.
WORKED EXAMPLE A
Represent x > 2 on a number line.
Model> is strict, so the circle at 2 is open (2 itself is excluded).
The range continues upward from 2, so the arrow points right, away from the circle.
WORKED EXAMPLE B
Represent x ≤ -1 on a number line.
Model≤ is non-strict, so the circle at -1 is filled (-1 itself is included).
The range continues downward from -1, so the arrow points left, away from the circle.

05

Learn

Read each card, then follow the worked examples one step at a time.

Reading a line

A number line shows two features. The circle: open is < or >, filled is ≤ or ≥. The arrow: right is greater than, left is less than.

a number line shows the inequality in two features - the circle (open = strict, < or >; filled = non-strict, ≤ or ≥) and the arrow direction (pointing right = greater than the marked value; pointing left = less than it).

Listing integers

Only whole numbers count. An open circle excludes the boundary from the list. A filled circle includes it.

only whole numbers count. Check the boundary using the circle - an open circle excludes that value from the list, a filled circle includes it.

Making the list finite

An inequality like x < 5 continues for ever in one direction. So the list needs an extra condition, such as 'x is a positive integer'.

a single inequality like x < 5 continues forever in one direction, so an extra condition such as 'x is a positive integer' is needed to give the list a natural stop.
WORKED EXAMPLE C
A number line shows a filled circle at 2 with the arrow pointing right. Model: filled circle = 2 is included = ≤ or ≥
arrow right = increasing from 2 = 'greater than'. Inequality: x ≥ 2.
WORKED EXAMPLE D
A number line shows an open circle at 5 with the arrow pointing left, and x is a positive integer. Model: open circle = 5 excluded = strict <
arrow left = 'less than'. Inequality: x < 5. Listing: positive integers below 5, excluding 5: x = 1, 2, 3, 4.

Write the inequality shown.
x > 3, because the open circle excludes 3 and the arrow points to the values above it
YOUR TURN · d

x ≤ 6, and since x is a positive integer the solutions are 1, 2, 3, 4, 5, 6.
