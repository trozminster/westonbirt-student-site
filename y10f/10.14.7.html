Topic 10.14 · Transformations · Lesson 7 of 7

Describing and Combining Transformations

A choreographer, a game designer and a textile printer all chain moves together. Each move needs a full description, and two moves can often be replaced by one.

By the end you’ll know…
  • A complete description names the transformation and gives everything that specifies it: a translation needs its column vector, a reflection its mirror line, a rotation its centre, angle and direction, and an enlargement its centre and scale factor.
  • Translations, reflections and rotations preserve length and angle, so they produce a congruent image; an enlargement with k not equal to 1 does not.
  • Two transformations performed one after the other can often be described as a single transformation.

Learn

What each description needs

A full description names the transformation and every fact that fixes it. Leave one out, and the image could land in a different place.

Which way round it faces

A reflection turns a shape over, so its image faces the other way round. A rotation or a translation keeps it facing the same way.

Congruent or only similar

Translations, reflections and rotations keep every length and angle, so the image is congruent. An enlargement changes the lengths, so its image is similar but not congruent.

WORKED EXAMPLE A

B faces the same way round, so it is not a reflection. The stem pointed up and now points right: a quarter turn clockwise. Tracing paper pinned at (0,0) turns A onto B.

The second acts on the first image

In a combination, the second transformation acts on the image the first one made. Carry them out in the order given.

Two moves, one description

Reflect in x=0, then in y=0
The image is a half turn about (0,0). So the pair is one rotation.

Reflecting in x=0 and then in y=0 lands on the same image as a half turn about (0,0). So the pair can be described as a single rotation.
