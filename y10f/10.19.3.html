Finding a Missing Angle

When two sides are known, trigonometry can also find an angle, such as the slope of a ramp or a roof. Today we run the ratio backwards.

By the end you’ll know…
  • When both sides of a ratio are known, the angle is recovered with the inverse function, written sin⁻¹, cos⁻¹ or tan⁻¹.
  • The inverse undoes the ratio, so from sin x = 0.5 comes x = sin⁻¹(0.5) = 30 degrees.
  • Because both papers allow a calculator, exact trigonometric values are not required at any point.
By the end you can
G5Calculate a missing angle in a right-angled triangle using the inverse sine, cosine or tangent.
G5Solve a two-dimensional problem that requires both a missing angle and a missing length to be found.

The inverse undoes the ratio

To find an angle from a ratio, use the inverse: sin⁻¹, cos⁻¹ or tan⁻¹. If sin x = 0.5, then x = sin⁻¹(0.5) = 30°.

When a ratio is known, the angle is found with the inverse function, written sin⁻¹, cos⁻¹ or tan⁻¹. If sin x = 0.5, then x = sin⁻¹(0.5) = 30°.

Two sides give the ratio

With two sides known, their ratio is worked out first. The inverse function then turns that ratio into the angle.

WORKED EXAMPLE A
Find x, to 1 decimal place.
Write the ratiosin x = 712
Use inverse sinx = sin⁻¹(7 ÷ 12)
Round to 1 d.p.x = 35.7°

Learn

Read each card, then follow the worked examples one step at a time.

An angle, then a length

Some problems need an angle and then a length, found one after the other. The angle found first is used in the second ratio.

Keep the full value

Rounding the angle before the second step can change the final answer. The calculator keeps the full value, so that is the one used again.

WORKED EXAMPLE C
A 12 m ramp rises 7 m. Find its angle x, then g.
Write the ratiosin x = 712
Use inverse sinx = sin⁻¹(712)
x = 35.685...° Round to 35.7° for the answer, but keep the full value for the next step.
Use cosg = 12 × cos 35.685...°
g = 9.746...
Angle35.7°
Length9.7 m
WORKED EXAMPLE D
A boat sails 6 km east, then 8 km north. Find x and d.
Write the ratiotan x = 68
Use inverse tanx = tan⁻¹(68)
x = 36.869...°
Bearing037°
Use cosd = 8 ÷ cos 36.869...°
Distanced = 10 km
