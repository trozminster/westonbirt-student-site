Direct Proportion and Unit Value

Recipes, shopping and wages all scale up and down in proportion. Today we find the value of one, then scale to any amount.

By the end you’ll know…
  • Two quantities are in direct proportion when doubling one doubles the other, so their ratio stays the same.
  • The unitary method finds the value of one item first, by dividing, and then multiplies to reach the quantity wanted.
  • Because the ratio is constant, a÷b is the same for every matching pair, which is the check on an answer.

Double one, double the other

Two quantities are in direct proportion when doubling one doubles the other. So 2 cakes need 300 g of flour, and 4 cakes need 600 g.

Find the value of one

The unitary method finds the value of one item first, by dividing. Then it multiplies to reach the amount wanted.

WORKED EXAMPLE A

Find one ticket27÷6=£4.50
Multiply by 1010×4.50=£45
WORKED EXAMPLE B

Find one cake360÷3=120 g
Multiply by 55×120=600 g

One multiplier for the table

In direct proportion, one multiplier turns every top value into the one below. If 2 hours earn £16, the multiplier is 8

In a table of direct proportion, one multiplier turns every top value into the value below it. If 2 hours earn £16, the multiplier is 8

Check every pair

The multiplier is checked on every pair, not just one. If one pair breaks the pattern, the table is not in proportion.
