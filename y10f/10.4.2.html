Probability from Venn Diagrams

A Venn diagram that has been filled in correctly is already a probability table: every element sits in exactly one region, so counting a region and dividing by n(ξ) is all a probability question needs. The work done last lesson placing elements is what makes this lesson short.

By the end you’ll know…
  • A probability read from a Venn diagram is the number of elements in a region divided by n(ξ); because every element appears exactly once, the region counts add up to n(ξ).

Why the regions can simply be counted

The denominator is always n(ξ), never the size of one circle. The numerator is the count in the region the question names.

A probability is the number of outcomes wanted divided by the number of outcomes possible, and on a Venn diagram both numbers are already written down. The denominator is always n(ξ), the whole universal set, because that is what is possible - never the size of one circle. The numerator is the count in the region the question describes. This works because every element appears exactly once, which is the same rule as last lesson seen from the other side: it is what makes the region counts add up to n(ξ) and stops anything being counted twice.

Union, intersection, complement

An intersection is the overlap alone. A union is both circles with the overlap counted once. A complement is n(ξ) minus the set.

Each of the three set operations names a different collection of regions, and the counting follows the name. An intersection is one region: the overlap. A union is three regions - both outer parts and the overlap - and the overlap is counted once, not once for each circle, which is exactly what 'at least one' means and why it is not the same question as 'both'. A complement is n(ξ) minus the count of the set itself, never a count taken from inside the set.

Reading the diagram backwards

A probability times n(ξ) gives back the region count. That count is a number of elements, so it must be a whole number.

A probability given in a question is a fact about a region count, and multiplying it by n(ξ) recovers that count. This is the same relationship as before, rearranged: if the count over n(ξ) is the probability, then the probability times n(ξ) is the count. What makes the answer checkable is that a region count is a number of elements, so it must come out a whole number. A fractional answer is not a smaller sort of answer here - it means either n(ξ) or the probability has been read wrongly.

Using the total to close the gap

The four regions must add to n(ξ). So one missing region can be found by subtraction alone.

A Venn diagram carries one more fact than the individual regions do: the four counts must add to n(ξ). That makes any single missing region recoverable by subtraction once the other three and the total are known, with no probability needed at all. When a probability is given as well, the two routes should agree, and checking one against the other is what catches an arithmetic slip before it reaches the answer.
WORKED EXAMPLE C
Given P(A ∩ B)=12, find the overlap.
The overlap count is P(A ∩ B) × n(ξ). Check from the total: 40−6−9−5 =20, so the two routes agree.
Overlap12×40=20
WORKED EXAMPLE D

Recover n(D) first: 35×50=30
