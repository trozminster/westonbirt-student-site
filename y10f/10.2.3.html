Topic 10.2 · Arithmetic Sequences · Lesson 3 of 3

Testing Membership and Term Position

An nth term rule is normally read forwards, position in and term out. Read backwards it answers two questions a list never could: is this number in the sequence at all, and if it is, where?

By the end you’ll know…
  • Substituting a term's value into the nth term rule and solving for n tests whether that value is actually a term of the sequence - it is a term only if n comes out as a positive whole number. The same equation, solved for n, gives the position of a known term.

Learn

The rule read backwards

To test a value, set the rule equal to it and solve for n. The position n must be a positive whole number. Otherwise the value is not a term.

Setting an nth term rule equal to a value turns it into an equation in n, and solving that equation is the whole of the membership test. What makes the answer meaningful is that n counts positions: it can only be a positive whole number. A solution that comes out negative, zero or fractional is not a smaller sort of membership - it means the value sits between the terms or before the sequence starts, and is not a term at all.

Two questions that look alike

A term's value and its position are easy to swap. To test 33, solve 4n + 1 = 33. The rule's output is the term; n is only the position.

A term's value and a term's position are easy to swap, and the swap produces an answer that looks perfectly reasonable. Asking whether 33 is a term hands you a value and wants a position back; substituting 33 as the position answers a question nobody asked, and the number it returns will be a genuine term of the sequence, which is exactly why the mistake survives checking. Reading the equation aloud - the rule equals 33 - keeps the two apart, because the rule's output is always the term and n is only ever the position.
TESTING FOR MEMBERSHIP
The nth term rule of a sequence is 5n - 3. Is 47 a term of this sequence?
Set the rule equal to the value. Set equal5n - 3 = 47
Add 35n = 50
Divide by 5n = 10
Check what n means10 is a positive whole number, so it is a genuine position. A whole number: 47 is the 10th term
TESTING 60
Now one that is not a term. Using the same rule 5n - 3, is 60 a term of this sequence?
Set the rule equal to the value. Set equal5n - 3 = 60
Add 35n = 63
Divide by 5n = 12.6
Check what n meansthere is no 12.6th position. 60 sits between the 12th term, 57, and the 13th, 62. Not a whole number: 60 is not a term

4n + 5 = 61 gives 4n = 56 and n = 14, a positive whole number, so 61 is the 14th term. Then 4n + 5 = 80 gives 4n = 75 and n = 18.75, which is not a whole number, so 80 is not a term.

Learn

Read each card, then follow the worked examples one step at a time.

The same equation, asked the other way

The membership equation also finds a term's position. The value of n it gives is that position.

When a value is known to be a term, the equation that tested membership answers a second question with no extra work: the value of n it produces is that term's position. Nothing about the method changes - only what the answer is called. This is why the membership test is worth doing properly even when membership is not in doubt, because a solved equation carries the position with it.

When the sequence decreases

A falling sequence has a negative coefficient of n. Keep that sign through every line of working. Dividing by a negative changes the sign of the result.

A falling sequence has a negative common difference, so its rule carries a negative coefficient of n, and the sign has to survive every line of the working. The step that catches people is the division: dividing both sides by a negative number changes the sign of what is left, and dropping that change gives a negative position, which no sequence has.
FINDING THE POSITION
The nth term rule of a sequence is 7n + 4. Which position does the term 60 occupy?
Set the rule equal to the value7n + 4 = 60.
Subtract 4 from both sides7n = 56. Step 3: Divide both sides by 7: n = 8.
Step 4: n is a positive whole number, so 60 is the 8th term.
DECREASING RULE
Now a decreasing sequence. The nth term rule is 50 - 3n. Which position does the term 14 occupy?
Set the rule equal to the value50 - 3n = 14.
Subtract 50 from both sides-3n = -36. Step 3: Divide both sides by -3. Both sides are negative
the answer is positive: n = 12.
Step 4: n is a positive whole number, so 14 is the 12th term. Check it forwards: 50 - 3 × 12 = 50 - 36 = 14.
YOUR TURN · c
The nth term rule of a sequence is 9n - 5. Which position does the term 67 occupy? Then: the nth term rule of a sequence is 80 - 6n. Which position does the term 20 occupy? Check the second one forwards before you accept it.
9n - 5 = 67 gives 9n = 72 and n = 8, so 67 is the 8th term. Then 80 - 6n = 20 gives -6n = -60 and n = 10, so 20 is the 10th term; checking forwards, 80 - 6 × 10 = 20.
