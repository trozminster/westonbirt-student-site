The Modal and Median Class

Grouped data have no single most common value or middle value. Today we find the class that holds each one.

By the end you’ll know…
  • The modal class is the class with the highest frequency, and it is a class, not a single value.
  • With unequal class widths the highest frequency need not be the most densely populated class, so the modal class must be quoted with care.
  • The class containing the median is found by counting through the frequencies to position (n+1)÷2

The modal class

The modal class is the class with the highest frequency. It is a class, such as 20<t≤30, not a single value.

The class containing the median

Count down the frequencies to position (n+1)÷2
With 30 values, the 15.5th lies in 20<t≤30

The median is at position (n+1)÷2, found by counting down the frequencies. With 30 values it is the 15.5th, which lies in 20<t≤30

Unequal classes need care

When classes have different widths, the highest frequency may come only from the widest class. So a modal class from unequal classes is quoted with care.

What each average shows

The modal class is the most common group. The median class is not pulled by an extreme class. The estimated mean uses every value, through the midpoints.

The modal class shows the most common group, and the median class is not pulled by an extreme class. The estimated mean uses every value, but only through the midpoints.

A reason from the data

Justify a choice of average from the data. A few huge values in a wide top class favour the median class.

A choice of average is justified by something in the data. A few very large values in a wide top class make the median class the better choice.
