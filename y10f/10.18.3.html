Topic 10.18 · Averages and Spread · Lesson 3 of 5

Estimating the Mean of Grouped Data

Surveys often record data in groups, such as ages 20 to 30
Today we estimate a mean when the exact values are lost.

By the end you’ll know…
  • When data are grouped the individual values are lost, so the mean can only be estimated.
  • The midpoint of a class is taken as representative of every value in it, and midpoint = (lower bound + upper bound) ÷ 2
  • Estimated mean = (sum of midpoint × frequency) / (total frequency).
  • The estimate is not the true mean, and it would only be exact if the values in every class were symmetrically spread about its midpoint.

Grouping hides the values

When data are grouped, the exact values are lost. So the mean of grouped data can only be estimated.

The midpoint stands for the class

Each value in a class is taken as its midpoint. The midpoint of 10<t≤20 is 15

Every value in a class is taken to be its midpoint, the lower bound plus the upper bound divided by 2
The midpoint of 10<t≤20 is 15

Estimate the mean

Multiply each midpoint by its frequency, and add. Divide by the total frequency. Here, 330÷20=16.5 minutes.

Each midpoint is multiplied by its frequency, the results are added, and the total is divided by the total frequency. Here that is 330÷20=16.5 minutes.

Why it is an estimate

The estimate treats every value in a class as its midpoint. It is exact only if values spread evenly about the midpoint.

The estimate treats every value in a class as its midpoint. It is exact only if the values in each class are spread evenly about the midpoint.

Too large or too small

If the values sit mostly below their class midpoints, the estimate is too large. If they sit mostly above, it is too small.
