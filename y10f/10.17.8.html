Solving Equations from Graphs

A graph already drawn can answer many equations, not just one. Today one horizontal line turns a curve into a set of solutions.

By the end you’ll know…
  • The solutions of f(x) = k are the x-coordinates of the points where the curve y = f(x) meets the horizontal line y = k.
  • Drawing that horizontal line across the graph is therefore the method, and each intersection gives one solution.
  • A solution read from a graph is an estimate, and it is quoted to the accuracy the grid supports.
By the end you can

Learn

A horizontal line finds them

To solve x² - 2x = 3, draw the line y = 3. Each crossing with y = x² - 2x gives a solution.

The solutions of x² - 2x = 3 are where the curve y = x² - 2x meets the line y = 3. Each crossing gives one solution.

Read to the grid's accuracy

A solution read from a graph is an estimate. Judge a crossing to the accuracy the grid supports.

A solution read from a graph is an estimate. Where a crossing falls between grid lines, it is judged to the accuracy the grid supports.

Learn

Read each card, then follow the worked examples one step at a time.

Above the line

The curve is above y = k where the function is greater than k. For x² > 4, that is x < -2 or x > 2.

The curve is above the line y = k wherever the function is greater than k. For y = x² against y = 4, that is outside the crossings: x < -2 or x > 2.

Below the line

Between the crossings the curve is below the line. So x² < 4 when -2 < x < 2. The answer is a range, not two numbers.

Between the two crossings the curve is below the line, so x² < 4 when -2 < x < 2. The answer is a range of x values, not two numbers.
