Solving Equations from Graphs

A graph already drawn can answer many equations, not just one. Today one horizontal line turns a curve into a set of solutions.

By the end you’ll know…
  • The solutions of f(x)=k are the x-coordinates of the points where the curve y=f(x) meets the horizontal line y=k.
  • Drawing that horizontal line across the graph is therefore the method, and each intersection gives one solution.
  • A solution read from a graph is an estimate, and it is quoted to the accuracy the grid supports.
By the end you can
G4Estimate the solutions of a quadratic equation by drawing a horizontal line on a pre-drawn graph and reading the intersections.
G5Use a pre-drawn graph to find the values of x for which the function is greater than, or less than, a given value.

Learn

Read each card, then follow the worked examples one step at a time.

Above the line

The curve is above y=k where the function is greater than k. For x2>4, that is x<−2 or x>2

The curve is above the line y=k wherever the function is greater than k. For y=x2 against y=4, that is outside the crossings: x<−2 or x>2

Below the line

Between the crossings the curve is below the line. So x2<4 when −2<x<2
The answer is a range, not two numbers.

Between the two crossings the curve is below the line, so x2<4 when −2<x<2
The answer is a range of x values, not two numbers.
