Set Notation and Venn Diagrams

Set notation is a way of saying exactly which things you mean, in symbols short enough to fit on one line. Once the notation is secure, the Venn diagram is just a picture of the same statements - and every probability question in this topic is answered by reading one.

By the end you’ll know…
  • A set is a collection of distinct elements, written with a capital letter and curly brackets; the universal set (ξ) is everything under consideration and the empty set (∅) has none. The complement A' is everything in ξ not in A, so n(A) +n(A') = n(ξ). B is a subset of A when every element of B is also in A.

Element of a set, or subset of it

An element belongs to a set: 3 ∈ A. A set sits inside a set: B ⊆ A. Check whether the left side is one element or a set.

A set is a collection of distinct elements, named with a capital letter and written inside curly brackets. Two different relationships can hold, and they are not interchangeable. An element belongs to a set: 3 ∈ A says the single thing 3 is one of A's members. A set sits inside another set: B ⊆ A says every member of B is also a member of A. The left-hand side is a single element in the first and a whole set in the second, which is the test for which symbol is wanted.

The universal set and the complement

The universal set ξ is the rectangle everything sits inside. The complement A' is everything in ξ that is not in A.

Every question is asked inside some agreed collection of things, and that collection is the universal set, ξ - drawn as the rectangle everything else sits inside. The complement A' is everything in ξ that is not in A, which is why n(A) +n(A') = n(ξ): between them the two account for the universal set exactly once each. The empty set ∅ is the set with no elements at all, and it is still a set. Elements belonging to none of the named sets have not disappeared - they sit inside the rectangle and outside every circle.

Learn

Read each card, then follow the worked examples one step at a time.

Every element has exactly one home

Every element of ξ goes in exactly one region. The sets it belongs to decide which region that is.

A Venn diagram is a picture of the same statements, and its one rule is that every element of ξ is written in exactly one region. The region is decided by the full list of sets the element belongs to: in both circles means the overlap, in one circle only means that circle's outer part, and in neither means inside the rectangle but outside both circles. Writing an element twice, or leaving one out because it belongs to no named set, breaks the count that every probability in this topic depends on.

Shading a set expression

Read a set expression from the inside out. In (A ∪ B)' the union is shaded first, then the dash reverses it.

A shaded region is the answer to a question about membership, and it is built by reading the expression from the inside out. For a compound expression like (A ∪ B)', the bracket is worked out first - the union, everything in either circle - and the dash then reverses it, so what gets shaded is everything the union leaves out, including the part of the rectangle outside both circles. Shading the union itself is the same expression with the complement forgotten, and the two pictures have nothing in common.

Both sets: 3 in the overlap. A only: 1, 2
