Translating with Column Vectors

A sliding door, a chess move and a character crossing a game screen all slide without turning. Two numbers are enough to say exactly where each one goes.

By the end you’ll know…
  • A translation is specified by a distance and a direction and is written as a column vector with the horizontal movement above the vertical.
  • A positive top number moves right and a negative one left; a positive bottom number moves up and a negative one down.
  • A translation preserves length and angle, so the image is congruent to the object and points the same way.
By the end you can
G3Translate a shape by a given column vector and write down the column vector of a translation shown on a grid.
G4Find the single translation equivalent to one translation followed by another.

A translation slides a shape

A translation moves every point the same distance in the same direction. The image is congruent to the object and faces the same way.

Top number across, bottom number up

A column vector puts the move across on top, up or down below. So (3−2) means 3 right and 2 down.

A column vector writes the movement across on top and the movement up or down below it. So (3−2) means 3 right and 2 down: a negative top moves left, a negative bottom moves down.

Learn

Read each card, then follow the worked examples one step at a time.

From a point to its own image

Count the vector from a point to its own image. Go across first, then up or down. Never count from the image back.

The vector of a translation is counted from any point to its own image: across first, then up or down. Count from the object to the image, never back.

One translation after another

Two translations one after the other make a single translation. Add the two top numbers, then add the two bottom numbers.
