Topic 10.3 · Linear Graphs · Lesson 1 of 4

Plotting Linear Graphs from Tables

An arithmetic sequence and a straight-line graph are the same object seen from two sides: dn + c and y = mx + c have the same shape because both are built from a constant step. This topic starts by turning an equation into points, which is the graph's version of substituting a position into a sequence rule.

By the end you’ll know…
  • A table of values generates coordinate pairs by substituting chosen x-values into an equation - in the same way that substituting a position n into an arithmetic sequence's nth-term rule generates a term.

A table of values turns an equation into points

A table of values turns an equation into coordinate pairs you can plot. Substitute each x-value into every term of the equation.

An equation in x and y states a relationship; it is not yet a picture. A table of values is what converts it into a list of coordinate pairs, and a coordinate pair is something that can be plotted. Each chosen x-value is substituted into the whole equation - every term of it, not just the term containing x - and the y-value that comes back is that x-value's partner. This is the same move as substituting a position into an nth term rule: an input goes in, an output comes out, and the equation itself does not have to be rearranged first. Any linear equation can be substituted into as it stands.

Why the points make one line and not a scatter

Equal steps in x give equal steps in y. So the points lie on one straight line, ruled right across the grid.

The pairs a linear equation produces are not scattered. Because x changes by the same amount along the top of the table, y changes by the same amount along the bottom, and a constant step in both directions is exactly what a straight line is. That is why the plotted points are joined with a single ruled line drawn right across the grid rather than with short segments between neighbours: every point between the plotted ones satisfies the equation too, and the line is a claim about all of them.

05

Learn

Read each card, then follow the worked examples one step at a time.

The same rule wearing two names

A sequence rule dn + c and a line y = mx + c match. One number is the step, the other the anchor.

An arithmetic sequence's rule dn + c and a linear equation y = mx + c are the same structure with different letters. In each, one number is the constant step - d between terms, m between y-values - and the other is where the pattern is anchored: c is the value one step back from the first term, and in the equation it is the value of y when x is 0
The reason the two look alike is that they are built the same way, from a starting value and a constant step, and neither needs any of the intermediate values to reach a distant one.

Why both produce evenly spaced results

Each step along adds the same amount: d or m. So the terms and the points are evenly spaced.

The constant step is what makes both patterns even. In a sequence, moving one position along adds d; on a line, moving one unit along the x-axis adds m. Because the increase never changes, the terms of the sequence are evenly spaced down a column and the points of the line are evenly spaced along it, which is the same fact said twice. The difference between them is only what the input is allowed to be: n counts positions and takes whole numbers, while x can take any value, which is why a sequence is a set of separate terms and a line is unbroken.

A FALLING PATTERN
Now the same argument on a falling pattern. The sequence 20, 17, 14, 11 has nth term rule 23−3n.
Step 1: d=17−20=−3, and c =20−(−3) =23, so the rule is 23−3n.
Step 2: The matching equation is y=23−3x, that is, m=−3 and c=23
Step 3: A negative constant step makes the sequence decrease and makes the line fall from left to right. It is the same number doing the same job in both.
