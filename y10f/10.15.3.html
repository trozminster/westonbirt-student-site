Topic 10.15 · Line Segments and Quadrilaterals · Lesson 3 of 5

Rearranging, Sketching and Checking Lines

Equations of lines do not always arrive in the form y = mx + c. Today we rearrange them, draw them, and check whether a point is on a line.

By the end you’ll know…
  • Michaelmas topic 3 already gives a line's gradient and y-intercept from its graph and from its equation, so this lesson starts from that and adds the four things it did not cover.
  • An equation written ax + by = c is rearranged into y = mx + c before it is drawn, using the same balancing moves as solving an equation.
  • A horizontal line has gradient 0 and an equation of the form y = k; a vertical line x = k has no gradient at all, because its horizontal change is 0 and nothing can be divided by 0.
  • When m is known but the line's crossing point is not on the grid, c is found by substituting the coordinates of any point on the line into y = mx + c and solving for c.
  • A point lies on a line exactly when its coordinates satisfy the equation, and that is the check on every answer here.
By the end you can
G4Draw the graph of a line given as ax + by = c by rearranging it into y = mx + c first, and write down the equation of a horizontal or a vertical line drawn on a grid.
G5Find c by substituting the coordinates of a point on the line into y = mx + c, and test whether a further point lies on that line.

Horizontal and vertical lines

A horizontal line y = k has gradient 0. A vertical line x = k has no gradient. Its change across is 0, and you cannot divide by 0.

A horizontal line y = k has gradient 0, because y never changes. A vertical line x = k has no gradient, because its change across is 0 and nothing can be divided by 0.

Learn

Read each card, then follow the worked examples one step at a time.

Find c from a point

With the gradient known, substitute a point into y = mx + c. Then solve for c. Gradient 3 through (2, 7) gives c = 1.

When the gradient is known, substitute a point on the line into y = mx + c and solve for c. A line with gradient 3 through (2, 7) gives 7 = 3 × 2 + c, so c = 1.

Check a point by substituting

A point is on a line when both coordinates fit the equation. (1, 4) fits y = 3x + 1: 3 × 1 + 1 = 4.

A point lies on a line exactly when both its coordinates fit the equation. For y = 3x + 1, (1, 4) fits because 3 × 1 + 1 = 4, but (2, 5) does not.
