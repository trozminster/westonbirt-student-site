Averages from a Frequency Table

Large data sets are summed up in a frequency table rather than a list. Today we find averages straight from the table.

By the end you’ll know…
  • In a frequency table each value carries a frequency, so the total of the values is the sum of value x frequency, and the number of values is the total frequency.
  • Mean = (sum of value x frequency) / (total frequency).
  • The modal value is the one with the highest frequency, and the median is found by counting through the frequencies to position (n+1)÷2
By the end you can

Each value comes with a frequency

In a frequency table, a value with frequency 7 appears 7 times in the data. So the total of the data is the sum of each value times its frequency.

The mean from the table

Divide that total by the total frequency, not the number of rows. Here, 51÷20=2.55 goals.

The mean is that total divided by the total frequency, not by the number of rows. Here it is 51÷20=2.55 goals.

The mode and the median

The mode is the value with the highest frequency. Count down the frequencies to the median, at position (n+1)÷2

The mode is the value with the highest frequency. The median is at position (n+1)÷2, found by counting down the frequencies.

Learn

Read each card, then follow the worked examples one step at a time.

Each average says something

The mean uses every value. One very large value pulls the mean up. It barely moves the median.

The mode is the most common value and the median is the middle one, while the mean uses every value. One very large value pulls the mean up but barely moves the median.

Choosing the average

Use the median when there is an extreme value. Use the mode when the data are not numbers. Use the mean when there are no extremes.

The median suits data with an extreme value, and the mode suits data that are not numbers. The mean suits data without extremes, because it uses every value.
