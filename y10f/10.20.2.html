Inequalities on a Number Line

A number line shows every value in a set at once, and makes it easy to count the whole numbers inside. Today we draw and read inequalities.

By the end you’ll know…
  • On a number line an open circle marks a value that is NOT included and a filled circle one that is, and an arrow shows that the set carries on.
  • A double-ended inequality such as 1 < x <= 5 is the region between two such marks, with the circle at each end matching its own symbol.
  • The integers that satisfy an inequality are the whole numbers lying inside the marked region, and an end value is one of them only where the circle is filled.
By the end you can
G5Represent an inequality, including a double-ended one, on a number line, using open and filled circles correctly.
G5List the integer values that satisfy a given inequality, including a double-ended one, and say how many there are.

The integers inside

The integers that satisfy an inequality are the whole numbers inside the marked stretch. An end value counts only where its circle is filled.
