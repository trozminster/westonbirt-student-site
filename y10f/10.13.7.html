Upper and Lower Bounds

A length given as 13 cm has been rounded, so the real length could be a little more or a little less. Bounds say exactly how far it could be out.

By the end you’ll know…
  • A rounded value stands for every value that would round to it, so it has a lower bound and an upper bound.
  • A value given to the nearest u has lower bound = value - u2 and upper bound = value + u2
  • The lower bound is reachable and the upper bound is not, so the error interval is written 12.5≤x<13.5 for 13 to the nearest whole number.

Half a unit either side

The bounds sit half a unit either side of a rounded value. So 13, to the nearest 1, lies from 12.5 to 13.5

A rounded value stands for every value that rounds to it. The bounds sit half a unit either side, so 13 to the nearest whole number lies from 12.5 up to 13.5

Find the unit first

First find the unit the value was rounded to. Then take half of that unit.

The unit is what the value was rounded to: the nearest 10, 1 decimal place, or a significant figure. Then take half of that unit.

Learn

One end in, one end out

The lower bound rounds to the value, so it takes ≤. The upper bound rounds up past it, so it takes <. For 13: 12.5≤x<13.5

The lower bound rounds to the value, but the upper bound rounds up past it. So the error interval uses ≤ on the left and < on the right: 12.5≤x<13.5

Is a value consistent?

A value fits a rounded measurement only if it lies in the error interval. 13.2 fits, but 13.5 does not, because it rounds to 14

WORKED EXAMPLE C
A height h is 1.7 m to 1 decimal place. Write its error interval.
