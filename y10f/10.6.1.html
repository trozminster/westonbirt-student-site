Topic 10.6 · Indices and Ratio · Lesson 1 of 4

Index Form and Index Laws

Index notation exists because writing a number multiplied by itself twenty times is unreadable. Once numbers are written that way, whole calculations can be done by working on the indices alone, which is far quicker than working on the numbers themselves.

By the end you’ll know…
  • An index says how many times the base is used as a factor (e.g. 2 to the power 5=2×2×2×2×2); multiplying powers of the same base adds the indices (am×an=am+n) and dividing subtracts them (am÷an=am−n). Any non-zero number to the power 0 is 1

The laws are just counting factors

An index counts how many times a base is used as a factor. Multiplying powers of one base adds the indices, and dividing subtracts them.

An index records how many times a base is used as a factor, so a product of two powers of the same base is simply a longer list of the same factor. Counting that longer list is what adding the indices does, which is why am×an=am+n rather than a(m×n). Dividing cancels factors from the list, so the indices subtract. Neither law says anything about the base, and neither works across different bases: 23×32 is a product of two different lists and cannot be collected into one power at all. Reading a law back to the list it came from is the reliable way to check it.

Why anything to the power 0 is 1

A power divided by itself is 1, and subtracting the indices gives 0
So a0 is 1 for every non-zero base.

Dividing a power by itself gives 1, because any non-zero quantity divided by itself does. Subtracting the indices for the same division gives an index of 0
Both descriptions are of the same calculation, so a0 must be 1 for every non-zero base, and this is a consequence of the division law rather than a separate rule to remember. The result is not 0, which is what the notation invites, and it does not depend on what the base is: 70, 1000 and 120 are all 1

Squares and cubes are indices

A square number is a number to the power 2
A cube number is a number to the power 3
'Squared' means index 2, never × 2

A square number is a whole number multiplied by itself, which is that number to the power 2; a cube number is one multiplied by itself twice more, to the power 3
So the familiar lists of squares and cubes are lists of powers, and recognising 64 as 82 or as 43 is reading the same number in two different index forms. This is worth having by heart, because it is how a number in a question is turned into a power that the laws can then act on. The word 'squared' means an index of 2 and never a multiplication by 2, which is the error the language invites.

Write the numbers as powers first

The laws apply once both parts are powers of the same base. A plain number is often a hidden power, since 8 is 23

A calculation written with squares and cubes can be simplified by the index laws as soon as every part is written as a power of the same base. 42×43 collects to 45 because the base is already shared. 22×8 does not look as though it shares a base, but 8 is 23, so rewriting it gives 22×23=25
Recognising that a plain number is a hidden power of the base is often the step that makes a law usable, and it works only when the number really is a power of that base.
