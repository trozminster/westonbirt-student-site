Laws of Indices

You already know that an index means repeated multiplication. Today you find shortcuts for combining powers of the same base without expanding them out fully - and what happens when a whole bracket is raised to a power.

By the end you’ll know…
  • An index says how many times the base is used as a factor: 25 =2×2×2×2×2
  • Multiplying powers of the same base adds the indices: am×an =am+n.
  • Dividing subtracts them: am÷an =am−n.
  • Any non-zero number to the power 0 is 1, since an÷an is both 1 and a0
  • A power outside a bracket applies to every factor inside: (2a)3 =23×a3 =8a3
  • The laws need the same base, so 23×32 cannot be combined.

Multiplying and dividing powers

An index counts how many times the base is a factor. Multiplying powers of the same base adds the indices. Dividing subtracts them.

An index says how many times the base is used as a factor: 25 =2×2×2×2×2
Multiplying powers of the SAME base adds the indices: am×an =am+n, since it's really just counting up all the factors together. Dividing subtracts them: am÷an =am−n, since matching factors cancel.

The power of zero

Any non-zero number to the power 0 is 1
Dividing an by an gives 1, and also a0
The laws need the same base.

Any non-zero number to the power 0 is 1, since an÷an must equal 1 (anything divided by itself), but the index law also gives an÷an=a0 - so a0=1
The laws only work when the base is the same, so 23×32 cannot be combined into a single power.

A power outside a bracket applies to every factor inside

A power outside a bracket applies to every factor inside. (2a)3 =23×a3 =8a3

(2a)3 means (2a)×(2a)×(2a), which separates into 23×a3=8a3 - the power applies to EVERY factor inside the bracket, not just one of them.

Applying it to numbers and combinations

Raise each factor inside to the outer power, then combine. So (3x)2 =32×x2 =9x2

The same rule applies whether the bracket contains a number and a letter, two numbers, or two letters: (3x)2=9x2, (5y)3=125y3, (ab)2 =a2b2
Each factor inside is raised to the outer power separately, then the results are combined.
