Topic 7.2 · Sets and Venn Diagrams · Lesson 6 of 6

Shading Venn Diagrams

Yesterday you decided which region an element belongs to. Today you work the other way: given an expression like A' ∩ B, you shade the region it describes - and given a shaded region, you write the expression that describes it.

By the end you’ll know…
  • A shaded region is the set of all elements the expression describes.
  • Read a compound expression inside out: brackets, then union and intersect, with ' applying to whatever it follows.
  • A' ∩ B means 'in B but not A'; (A ∪ B)' means 'in neither'.
  • Different expressions can give the same region: (A ∪ B)'=A' ∩ B'.
By the end you can

Reading an expression

Shade every element the expression describes. Work in brackets first, then ', then ∪ or ∩. A ∩ B shades only the overlap.

A shaded region shows every element the expression describes. Work inside brackets first, then apply ' (complement), then ∪ or ∩ to combine. A ∩ B means shade only where both circles overlap; A ∪ B means shade everywhere either circle covers.

Complements in a shaded diagram

A' is everything outside circle A, inside ξ. So A' ∩ B is the part of B outside A.

A' means shade everywhere OUTSIDE circle A but still inside the rectangle ξ - including inside circle B where B doesn't overlap A.A' ∩ B means shade the part of B that is outside A.

Learn

Read each card, then follow the worked examples one step at a time.

Naming the region a shading shows

For each circle, decide whether the region is inside or outside it. Combine those answers with ∩ to name the region.

A shaded region is named by what is true of it for each circle - whether it sits inside that circle or outside it. Those answers combine with ∩ where the region is a single connected one, matching the pattern of which circles it touches.

Same region, different expression

Different expressions can describe the same region. B ∩ A' and (A ∪ B) ∩ A' both shade B outside A.

More than one expression can describe the same shaded region - B ∩ A' and (A ∪ B) ∩ A' shade exactly the same area (the part of B outside A), because 'in A or B, but not in A' leaves only what is in B and not in A.
