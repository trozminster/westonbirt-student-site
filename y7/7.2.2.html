Complements and Subsets

If a set is 'everyone in this class', then its complement is 'everyone under this roof who is NOT in this class' - just as useful a group to know about as the set itself. Today adds two ideas that let you compare sets to each other: what's left over when you take a set away from everything (its complement), and when one set is entirely swallowed by another (a subset).

By the end you’ll know…
  • The complement A' is every element of the universal set not in A.
  • Every element is in exactly one of A or A', so n(A) + n(A') = n(ξ).
  • B is a subset of A (B subset-of A) when every element of B is also in A.
  • Every set is a subset of itself, and the empty set is a subset of every set.
  • Groups of numbers (evens, primes, squares, multiples of n) are commonly used as sets, some subsets of others.

The complement

The complement A' is every element of ξ not in A. Each element is in A or A', never both.

The complement of A, written A', is every element of the universal set that is NOT in A. Every element of ξ is in exactly one of A or A' - never both, never neither.

Counting the complement

The counts add up: n(A) + n(A') = n(ξ). Know two, and subtract to find the third.

Since every element is in exactly one of A or A', n(A) + n(A') = n(ξ). So if you know two of the three counts, you can find the third by subtracting.
WORKED EXAMPLE A
Let ξ = {1,2,...,10} and M = {1,3,5,7,9}. Write M'.
Complementeverything in ξ that is not in M
Check 1 to 10every odd number is in M, every even number is not
M'{2, 4, 6, 8, 10}
WORKED EXAMPLE B

N and N' togethermake up all of ξ, with no overlap
n(N')20 - 8 = 12

Subsets

B is a subset of A when every element of B is in A. B can equal A but never contain anything extra.

B is a subset of A (B ⊆ A) when every element of B is also in A - B can be smaller than A, or exactly equal to it, but never contain anything extra. Every set is a subset of itself, and the empty set is a subset of every set.

Spotting subsets

Check a subset element by element, not by its name.

Groups of numbers - evens, primes, squares, multiples of a number - are commonly used as sets, and some are subsets of others - but whether one set is a subset of another is settled by checking its elements one at a time, never by the pattern the set is named by.

Let CC = {2,3} and DD = {1,2,3,4,5}. Is CC a subset of DD?
Yes. 2 and 3 are both in DD, so CC ⊆ DD.
Not quite. Size doesn't decide it. Check every element: 2 and 3 are both in DD.
Not quite. A subset doesn't have to equal the set. Every element of CC is in DD.
Not quite. Backwards: CC's elements are all in DD, so CC ⊆ DD.
Let EE = {primes less than 10} and FF = {odd numbers less than 10}. Is EE a subset of FF?
Yes. 2 is prime but not odd, so EE isn't a subset of FF.
Not quite. Every element must be in FF. 2 isn't, so no.
Not quite. Size doesn't decide it. It's no because 2 isn't in FF.
Not quite. Check the elements: 2 is in EE but not in FF.
Is the empty set a subset of every set?
Yes. The empty set has nothing that could be missing from another set.
Not quite. It has no elements, so none can fail the test. It's a subset of every set.
Not quite. It's always true: there's nothing in it to check.
Not quite. There's no such rule. The empty set is a subset of every set.
