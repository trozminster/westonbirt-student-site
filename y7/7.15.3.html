Solving Inequalities

A phone plan caps your spending and a lift caps its load. Today you solve inequalities the way you solve equations, and show every value that works.

By the end you’ll know…
  • An inequality is solved like an equation, by applying inverse operations to both sides.
  • The answer is a range of values, written in inequality notation rather than as x = a single number.
  • The sign stays the same way round when adding, subtracting, multiplying or dividing by a positive number.
  • A solution set can be shown on a number line, or listed as the integers it contains.
By the end you can
G4Solve one- and two-step inequalities, giving the answer in inequality notation.
G5Solve an inequality and represent its solution set on a number line, listing integer solutions where asked.

Solving like an equation

Solve an inequality like an equation, using inverse operations on both sides. Adding, subtracting, or multiplying or dividing by a positive keeps the sign.

An inequality is solved like an equation, by doing the same inverse operation to both sides. Adding, subtracting, or multiplying or dividing by a positive number keeps the sign the same way round.

The answer is a range

The solution is a range, never x = one number. So x < 4 means every number below 4 works.

The solution is a range of values written with the inequality sign, never as x = one number. x < 4 means that every number below 4 works.

Showing the solution

Once solved, the solution set is shown on a number line exactly as before. The circle is set by the symbol and the arrow by its direction.

Listing the solutions

The integer solutions are the whole numbers in the solution set. A strict symbol leaves the boundary out.

The integer solutions are the whole numbers in the solution set, and a question may add a condition such as positive. A strict symbol leaves the boundary out.
