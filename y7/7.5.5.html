Order of Operations

You're now fluent with all four operations, including negatives, powers and roots. Today's skill decides which one happens first when a calculation mixes several of them - because the order genuinely changes the answer.

By the end you’ll know…
  • Operations run in a fixed order: Brackets, Indices, Multiplication and Division, Addition and Subtraction.
  • Multiplication and division rank equally, as do addition and subtraction; equal ranks work left to right.
  • A fraction bar and a root sign group everything inside them, acting as invisible brackets.
  • Brackets override the default order, which is why inserting them changes the answer.
By the end you can

BIDMAS

Operations run in a fixed order: Brackets, Indices, Multiplication and Division, Addition and Subtraction. Operations of equal rank go left to right.

Operations run in a fixed order: Brackets, Indices, Multiplication and Division, Addition and Subtraction. Multiplication and division rank equally with each other, as do addition and subtraction - when two operations of equal rank appear together, they're done left to right.

Invisible brackets

A fraction bar groups its top and its bottom like brackets. A root sign groups everything inside it too. Brackets override the usual order.

A fraction bar groups everything above and below it as if in brackets, and a root sign groups everything inside it the same way - both must be fully simplified before dividing or rooting. Brackets themselves override the default order entirely, which is why inserting them into a calculation can change its answer.

Inserting brackets

Inserting brackets forces a different order. First work out the answer without brackets. Then test where brackets would change it.

Brackets can be inserted into a calculation to force a different order and make a target answer true. To find where they go, work out what the calculation gives without brackets, then test where forcing an earlier addition or subtraction would change the result to match the target.

Spotting errors in worked calculations

An error usually does an addition or subtraction too early. Check each step against BIDMAS, not just the arithmetic.

A worked calculation that breaks the order of operations usually does an addition or subtraction before a multiplication, division, bracket, or index that should have come first. Finding the error means checking each step against BIDMAS, not just checking the arithmetic itself.
