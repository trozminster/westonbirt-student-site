Topic 7.12 · Representing Data · Lesson 1 of 4

The Data Handling Cycle

Every survey or experiment follows the same four-part cycle before it can answer a question. Today you learn the cycle itself, and how to sort data so the right kind of chart gets chosen.

By the end you’ll know…
  • The data handling cycle runs hypothesis, collect, represent, analyse, conclude, and can be repeated.
  • A hypothesis is a statement the data can support or contradict.
  • Discrete data takes separate fixed values; continuous data can take any value in a range.
  • Primary data is collected first-hand; secondary data comes from someone else.

The data handling cycle

An investigation runs through four stages: hypothesis, collect, represent, analyse. Its conclusion can send the cycle round again. A hypothesis is a statement, not just a question.

An investigation runs through four stages - hypothesis, collect, represent, analyse - ending in a conclusion that can send the cycle round again. A hypothesis is a statement the data can support or contradict, not just a question.

Discrete or continuous

Discrete data takes separate values, like the number of pets. Continuous data takes any value in a range, like a height.

Discrete data can only take separate fixed values, with nothing sensible in between - like the number of pets a family owns. Continuous data can take any value in a range - like a height or a time - even if it happens to be recorded as a whole number.
WORKED EXAMPLE A
Classify "the number of goals scored in a match" and "the time taken to run 100 m" as discrete or continuous.
Goalsonly whole numbers possible, nothing between 2 and 3 goals — Discrete
Timeany value possible between two whole seconds — Continuous
WORKED EXAMPLE B
A student times her own 100 m run with a stopwatch, then looks up the world record time online. Classify each source.
Own timingcollected first-hand, for this investigation — Primary
World recordtaken from an existing source — Secondary

YOUR TURN · b

Choosing a representation

Choose the chart by what the data is, not by habit. Name the data type first.

The right representation depends on what the data is, not on habit - discrete category counts, grouped continuous data and single measures each suit a different chart. Naming the data correctly comes before choosing how to show it.

Reading the cycle back to front

A chart answers the hypothesis only if it fits the data. A chart that does not fit breaks the cycle.

A representation and an analysis only answer the hypothesis if they were chosen to match the data collected; picking a chart that does not fit the data breaks the cycle at that step.
WORKED EXAMPLE C
A class records how many pets each of 30 students owns. Which representation suits this data, and why?
Datanumber of pets, a whole number per student
Discrete category counts
Representationbar chart or pictogram
WORKED EXAMPLE D
A class records the heights of 30 plants, grouped into 5cm class intervals. Which representation suits this data, and why?
Dataheight, grouped into class intervals
Grouped continuous data
Representationfrequency polygon
YOUR TURN · c
A class records the colour of 30 cars passing the school. Which representation suits this data, and why?
Data: colour, a category with no order; discrete category counts; a bar chart or pictogram suits it.
YOUR TURN · d
A class records the time, in minutes grouped into 10-minute intervals, each student spends on homework. Which representation suits this data, and why?
Data: time, grouped into class intervals; grouped continuous data; a frequency polygon suits it.
