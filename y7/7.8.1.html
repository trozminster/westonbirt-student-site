Mean, Median, Mode and Range

A whole data set is hard to describe in one number - averages and range let you summarise it. Today you meet all three types of average plus the range, and the many ways each one can trip you up if you rush the ordering or the counting.

By the end you’ll know…
  • The mean is the total of the values divided by how many there are, sharing the total equally.
  • The median is the middle value once the data is in order; with an even number of values it is halfway between the middle two.
  • The mode is the most frequent value, and there can be more than one or none at all.
  • The range is the largest value minus the smallest, and measures spread rather than a typical value.

Median and mode

The median is the middle value once the data is in order. With an even count, it is halfway between the middle two. The mode is the most frequent value.

The median is the middle value once the data is in order - with an even number of values it is halfway between the middle two. The mode is the most frequent value, and a data set can have more than one mode, or none at all.

Range

The range is the largest value minus the smallest. It measures spread, not a typical value.

The range is the largest value minus the smallest, and it measures spread, not a typical value - a small range means the data is tightly grouped, a large range means it's spread out.

Learn

The mean

The mean is the total divided by how many values there are. Every value counts, however many times it repeats.

The mean is the total of the values divided by how many there are, sharing the total equally between them. Every value counts once towards the total AND once towards the count, however many times a value repeats.

Counting every value, including repeats

Divide by the number of values, not the number of different values. A repeated value counts each time it appears.

The mean divides by the total NUMBER of values in the list, not by the number of different values - a repeated value still counts once for each time it appears.
WORKED EXAMPLE C
Find the mean of 5, 8, 11, 4, 7
Add the values5+8+11+4+7=35
Count them5 values
Divide by the countmean=35÷5
=7
WORKED EXAMPLE D
Find the mean of 3, 3, 3, 9
Add the values3+3+3+9=18
Count them4 values, because a repeated value still counts each time
Divide by the countmean=18÷4
