Topic 7.6 · Introducing Algebra · Lesson 5 of 5

Collecting Like Terms

You've multiplied algebraic terms - today you combine them a different way, by adding and subtracting like terms, which behaves completely differently from multiplying them. Confusing the two rules is the single most common algebra error at this stage, so get very clear today which rule applies when.

By the end you’ll know…
  • Like terms have exactly the same letters raised to exactly the same powers; only the coefficients differ.
  • Like terms are combined by adding or subtracting the coefficients, leaving the letter part unchanged: 5x+2x=7x.
  • Unlike terms (3x and 3y, or x and x2) cannot be combined into one term.
  • The sign in front of a term belongs to it and travels with it.
  • A function machine shows, in order, the operations applied to an input to give an output.
  • Multiplying powers of the same base adds the indices: x2×x3=x5
By the end you can

Adding vs multiplying like terms

Adding like terms keeps the power: x2+x2=2x2
Multiplying adds the powers: x2×x2=x4

Adding like terms combines the coefficients and leaves the powers unchanged: x2+x2=2x2
Multiplying terms multiplies the coefficients and adds the powers: x2×x2=x4
These look deceptively similar because the same terms appear in both.

The general rule

Multiplying powers of the same base adds the indices: x2×x3=x5
The index counts every x used as a factor.

Multiplying powers of the same base adds the indices: x2×x3=x5, because it's really just counting up all the x's used as factors together: (x.x)×(x.x.x) =x.x.x.x.x.
