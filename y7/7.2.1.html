Introducing Sets

You already sort things into groups without thinking about it - your left shoe from your right, spam email from real email, even numbers from odd. Maths has a precise way to talk about any such group: a set. Today you'll learn the notation mathematicians use to write down exactly what's in a group, what's outside it, and how many things it contains.

By the end you’ll know…
  • A set is a collection of distinct elements; order does not matter and nothing is listed twice.
  • A set takes a capital letter, with its elements in curly brackets: A ={2,4,6}.
  • 'a ∈ A' means a is an element of A; 'a ∉ A' means it is not.
  • The universal set (ξ) is everything under consideration in the question.
  • The empty set (∅, or {}) has no elements.
  • n(A) is the number of elements in A.

Sets and notation

A set is a collection of distinct elements. It is written with curly brackets: A ={2,4,6,8}. The sign ∈ means is an element of.

A set is a collection of distinct objects (elements) - nothing is listed twice and order doesn't matter. A set is named with a capital letter and its elements written inside curly brackets: A ={2,4,6,8}.'a ∈ A' means a is an element of A; 'a ∉ A' means it isn't.

Universal and empty sets

The universal set ξ is everything in the question. The empty set, { }, contains nothing.

The universal set (ξ) is everything under consideration in the question - every other set in that question is built from its elements. The empty set (written empty or {}) contains nothing at all.

Counting a set

The count n(A) is the number of elements in A. Count each distinct element once. For a rule, list every value first, then count.

n(A) means "the number of elements in set A" - count each distinct element once, however the set is written. If A is given as a list, count the items in the list. If A is described by a rule ("multiples of 5 less than 30"), list every value the rule produces first, then count how many there are.

Counting a rule-based set carefully

Work through the rule from the smallest value to the largest. Check each value near the boundary exactly.

work through the rule systematically from the smallest qualifying value to the largest, checking each one satisfies the rule exactly, so nothing near the boundary is missed or wrongly included. n(A) is the count of values that survive this check, not the set itself.
