Frequency Polygons

Grouped continuous data cannot be shown one value at a time, so it needs a chart built from class intervals. Today you learn to draw and read a frequency polygon.

By the end you’ll know…
  • Grouped data collects values into class intervals, each with its own frequency.
  • The midpoint of a class interval is halfway between its endpoints and represents the whole class.
  • A frequency polygon plots frequency against midpoint and joins the points with straight lines.
  • The shape of the polygon shows where the data clusters and how spread out it is.

Class intervals and midpoints

Grouped data puts values into class intervals. Each interval plots at its midpoint, halfway between its endpoints. A frequency polygon joins those points with straight lines.

Grouped data collects values into class intervals, each with its own frequency; the midpoint of an interval is halfway between its two endpoints and stands in for every value in that class. A frequency polygon plots frequency against midpoint for each interval, then joins the plotted points with straight lines.

Why the midpoint

The midpoint fairly represents every value in the interval.

Using the midpoint is the fairest single value to represent a whole interval, since it sits exactly between the smallest and largest possible value in that class.

05

Learn

Read each card, then follow the worked examples one step at a time.

Joining the points

Join consecutive points with straight lines, never a curve. Plot the points in the order of the intervals.

Once every midpoint-frequency point is plotted, the polygon is completed by joining consecutive points with straight lines - never a smooth curve. Points are plotted in order of the class intervals, so the line moves steadily across the grouped range.

Shape and spread

The polygon's peak shows where the data clusters. A wide, flat polygon means the data is spread out.

Where the polygon rises highest shows where the data clusters, and how spread out the points are along the horizontal axis shows the spread of the whole data set. A narrow, tall polygon means the data is tightly clustered; a wide, flat polygon means the data is spread out.

A grouped frequency table gives midpoints 5, 15, 25 with frequencies 2, 9, 3
Describe the frequency polygon.
Points(5,2), (15,9), (25,3)
