Piecewise Functions

A taxi charges one rate for the first few miles and another after that: one function, two rules. Today we read, draw and solve functions built from pieces.

By the end you’ll know…
  • A piecewise function uses different rules on different parts of its domain, each rule written with its own interval.
  • To evaluate it, first find the interval the input lies in, then use that rule only.
  • At a boundary the inequality signs say which rule owns the point: x<3 excludes 3, and x≥3 includes it.
  • Its graph is drawn piece by piece, each rule over its own interval only, with an open circle at an excluded end.
  • f(x)=k is solved rule by rule, and a solution is kept only if it lies in that rule's interval.
By the end you can
G8Evaluate a piecewise function and sketch its graph from linear and quadratic pieces.
G8Solve f(x)=k for a piecewise function, rejecting any solution outside its own interval.

The interval chooses the rule

A piecewise function has a different rule on each interval. The input's interval decides which rule applies.

Drawn in pieces

Each rule is drawn over its own interval only. An excluded end gets an open circle.

Learn

Read each card, then follow the worked examples one step at a time.

Each rule, then a check

Each rule can give solutions of f(x)=k. A solution counts only inside its own rule's interval.

The line y=k meets each piece

A horizontal line y=k meets the graph at every solution. Where it misses a piece, that rule gives none.
