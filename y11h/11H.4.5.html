Forming Equations from Probabilities

Exam questions often hide a number: a bag with n sweets, or a box with some counters missing. The probability given is enough to find it, because a probability written with n is an equation waiting to be solved.

By the end you’ll know…
  • When a bag holds an unknown number of items, each probability is an algebraic fraction: with n sweets of which 6 are orange, P(orange) = 6n.
  • Without replacement both counts fall by one for the second pick, so P(two orange) = 6n×5n−1; with replacement it is 6n×6n.
  • Setting the expression equal to the given probability makes an equation, which is cleared of fractions and is usually a quadratic.
  • Only a positive whole number can be a count, so any other root is rejected.
By the end you can
G8Form an equation from a probability involving an unknown number of items, with or without replacement.
G8Solve the equation, reject any root that cannot be a count, and use the count to find a further probability.
