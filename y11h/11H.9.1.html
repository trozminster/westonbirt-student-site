Topic 11H.9 · Functions and Graph Transformations · Lesson 1 of 11

Using Function Notation

A function is a rule with a name, so f(3) says exactly which rule to use on which input. This notation is the language of the whole topic: domains, composites, inverses and graph transformations.

By the end you’ll know…
  • A function is a rule that gives exactly one output for each input, like a function machine.
  • f(x) = 3x + 2 names the rule f, and f(4) is the output when the input is 4: f(4) = 3 × 4 + 2 = 14. The same rule may be written f: x -> 3x + 2.
  • The x in the rule is a placeholder, so f(-2), f(a) and f(2x) replace every x with that input, in a bracket.
  • f(x) = k is an equation asking which input gives the output k, so it is solved for x, not substituted into.
By the end you can
G6Evaluate a function for a numerical or algebraic input, such as f(-3) or f(2a).
G6Solve equations written in function notation, such as f(x) = 17 or f(x) = g(x).

Learn

One input, one output

A function is a rule giving exactly one output for each input. Here the rule f(x) = 3x + 2 multiplies by 3, then adds 2.

The input replaces x

In f(4), the input 4 replaces every x. A negative or algebraic input goes in a bracket.

WORKED EXAMPLE A
f(x) = x² - 3x. Find f(-2).
Substitute -2 for xf(-2) = (-2)² - 3 × (-2)
= 4 + 6
= 10
WORKED EXAMPLE B
f(x) = x² - 3x. Find f(2a).
Substitute 2a for xf(2a) = (2a)² - 3 × 2a
= 4a² - 6a
YOUR TURN · a

2 × 9 + 5 = 23

2(a + 1)² + 5 = 2a² + 4a + 7

Learn

Read each card, then follow the worked examples one step at a time.

Working backwards

An equation f(x) = k asks which input gives the output k. So it is solved for x, never substituted into.

Two rules, one output

Setting f(x) = g(x) finds the input where both rules agree. Write each rule out, then solve.

WORKED EXAMPLE C
f(x) = 5x - 7. Solve f(x) = 18.
Write the equation5x - 7 = 18
Add 7 to both sides5x = 25
x = 5
WORKED EXAMPLE D
f(x) = 4x - 1 and g(x) = x + 11. Solve f(x) = g(x).
Set the rules equal4x - 1 = x + 11
Subtract x, then add 13x = 12
x = 4
YOUR TURN · c
f(x) = x + 32. Solve f(x) = 7.
x + 3 = 14, so x = 11
YOUR TURN · d

x² = 25, so x = 5 or x = -5
