Topic 11H.9 · Functions and Graph Transformations · Lesson 1 of 11

Using Function Notation

A function is a rule with a name, so f(3) says exactly which rule to use on which input. This notation is the language of the whole topic, from domains and composites to inverses and graph transformations.

By the end you’ll know…
  • A function is a rule that gives exactly one output for each input, like a function machine.
  • f(x)=3x+2 names the rule f, and f(4) is the output when the input is 4: f(4) =3×4+2 =14
    The same rule may be written f: x−>3x+2
  • The x in the rule is a placeholder, so f(−2), f(a) and f(2x) replace every x with that input, in a bracket.
  • f(x)=k is an equation asking which input gives the output k, so it is solved for x, not substituted into.
By the end you can
G6Evaluate a function for a numerical or algebraic input, such as f(−3) or f(2a).
G6Solve equations written in function notation, such as f(x)=17 or f(x) =g(x).

Working backwards

An equation f(x)=k asks which input gives the output k. So it is solved for x, never substituted into.

Two rules, one output

Setting f(x)=g(x) finds the input where both rules agree. Write each rule out, then solve.

WORKED EXAMPLE C

Solve f(x)=18
Write the equation5x−7=18
Add 7 to both sides5x=25
x=5
