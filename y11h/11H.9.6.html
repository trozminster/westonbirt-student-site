Finding Inverse Functions

Converting °C to °F is a function, and converting back is its inverse: the same steps undone in reverse. Today we find inverse functions, by machine and by algebra.

By the end you’ll know…
  • The inverse function f−1 reverses f: if f(3)=11, then f−1(11)=3
  • It undoes the steps of f in reverse order, like a function machine run backwards.
  • To find f−1(x), write y=f(x), make x the subject, then write the result with x as the input.
  • f−1(x) is not 1f(x): the −1 names the inverse, not a reciprocal.
  • Applying a function and then its inverse returns the input: f−1(f(x)) =x.

Undo in reverse order

The inverse function f−1 undoes f. Its steps undo those of f, in reverse order.

A root undoes a power

A power is undone by the matching root. In 2x3+1 the cube is applied first, so it is undone last.

x in the denominator

When x is in a denominator, multiplying clears it. Then x stands alone after one more step.
