Finding Inverse Functions

Converting °C to °F is a function, and converting back is its inverse: the same steps undone in reverse. Today we find inverse functions, by machine and by algebra.

By the end you’ll know…
  • The inverse function f⁻¹ reverses f: if f(3) = 11, then f⁻¹(11) = 3.
  • It undoes the steps of f in reverse order, like a function machine run backwards.
  • To find f⁻¹(x), write y = f(x), make x the subject, then write the result with x as the input.
  • f⁻¹(x) is not 1f(x): the -1 names the inverse, not a reciprocal.
  • Applying a function and then its inverse returns the input: f⁻¹(f(x)) = x.

Undo in reverse order

The inverse function f⁻¹ undoes f. Its steps undo those of f, in reverse order.

Make x the subject

Algebraically, write y = f(x) and make x the subject. Then rename the input x.

WORKED EXAMPLE A
f(x) = 2x + 7. Find f⁻¹(x).
Reverse the steps- 7, then ÷ 2
f⁻¹(x) = x - 72
WORKED EXAMPLE B
f(x) = x + 45. Find f⁻¹(x) and f⁻¹(3).
Name the output yy = x + 45
Make x the subjectx = 5y - 4
f⁻¹(x) = 5x - 4
f⁻¹(3) = 11

Learn

Read each card, then follow the worked examples one step at a time.

A root undoes a power

A power is undone by the matching root. In 2x³ + 1 the cube is applied first, so it is undone last.

x in the denominator

When x is in a denominator, multiplying clears it. Then x stands alone after one more step.

WORKED EXAMPLE C
f(x) = (x - 2)³. Find f⁻¹(x).
Name the output yy = (x - 2)³
Take the cube root∛y = x - 2
f⁻¹(x) = ∛x + 2
WORKED EXAMPLE D
f(x) = 8x + 3. Find f⁻¹(x).
Name the output yy = 8x + 3
Multiply, then divide by yx + 3 = 8y
f⁻¹(x) = 8x - 3
YOUR TURN · c
f(x) = 5x² - 2 for x ≥ 0. Find f⁻¹(x).
x² = y + 25, so f⁻¹(x) = √(x + 25)
YOUR TURN · d

y - 1 = 12x, so g⁻¹(x) = 12x - 1
