Topic 11H.9 · Functions and Graph Transformations · Lesson 8 of 11

Reading Functions from Graphs

A graph shows every input and output of a function at once, so many answers can be read before any algebra. Today we read values, solve f(x) = k, and draw an inverse from the picture.

By the end you’ll know…
  • The graph of y = f(x) plots each input x against its output f(x), so f(a) = b means the point (a, b) lies on the graph.
  • f(x) = k is solved by reading the x-values where the line y = k meets the graph, and the roots of f(x) = 0 are where the graph crosses the x-axis.
  • The domain is the span of x-values the graph covers, and the range is the span of its heights.
  • The graph of y = f⁻¹(x) is the reflection of y = f(x) in the line y = x, because the inverse swaps each point (a, b) to (b, a).
By the end you can

Learn

Read each card, then follow the worked examples one step at a time.

A point is an input and its output

Each point (a, b) on y = f(x) says f(a) = b. So f(a) is read up from x = a.

Across from y = k

Solving f(x) = k reads across from the height k. Every crossing gives a solution.

05

Learn

Read each card, then follow the worked examples one step at a time.

Inputs and outputs swap

The inverse swaps each point (a, b) to (b, a). So y = f⁻¹(x) is y = f(x) reflected in y = x.

Read the inverse backwards

The inverse at b is the input that gave the output b. On the graph of f, it is read across from b, then down.

WORKED EXAMPLE C
f(x) = 2x² for x ≥ 0. Use its graph to find f⁻¹(8).
Read across from 8, then downf⁻¹(8) = 2
