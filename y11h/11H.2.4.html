The Cosine Rule for Lengths

Given two sides and the angle between them, no side-and-opposite-angle pair is known, so the sine rule cannot start. Today we use the cosine rule, which extends Pythagoras to every triangle.

By the end you’ll know…
  • In any triangle, a² = b² + c² - 2bc cos A, where A is the angle between the sides b and c, and a is opposite it.
  • The cosine rule is used when the given angle is enclosed by the two given sides, so no complete side-and-opposite-angle pair is known.
  • When A = 90 degrees, cos A = 0 and the rule becomes Pythagoras.
  • When A is obtuse, cos A is negative, so the last term is added and the opposite side is longer.

02

Learn

Read each card, then follow the worked examples one step at a time.

The angle between the two sides

The cosine rule uses two sides and the angle between them. It finds the third side, opposite that angle.

Subtract the whole last term

The term 2bc cos A is worked out first, then subtracted. Subtracting before multiplying gives nonsense.

WORKED EXAMPLE A
In triangle ABC, b = 7 cm, c = 8 cm and A = 60°. Find a.
Write the rulea² = b² + c² - 2bc cos A
Substitutea² = 49 + 64 - 112 cos 60° = 57
Square roota = √57
a = 7.55 cm
WORKED EXAMPLE B
In triangle ABC, b = 5 cm, c = 9 cm and A = 120°. Find a.
Substitutea² = 25 + 81 - 90 cos 120°
Cosine is negativea² = 106 + 45
= 151

a = 12.3 cm

A pair or an angle between

Look for a side with its opposite angle. A complete pair calls for the sine rule; otherwise use the cosine rule.

Decide, then solve

Write down what is given before choosing. The choice of rule is part of the working.
