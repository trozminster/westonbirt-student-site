Domain and Range

A calculator shows an error for −4 or 1÷0, because some inputs cannot be used. Today we find which inputs a function accepts, and which outputs it can ever give.

By the end you’ll know…
  • The domain of a function is the set of inputs it may take, and the range is the set of outputs it produces.
  • An input is excluded from the domain when the rule cannot use it: a denominator cannot be 0, and a square root cannot take a negative number.
  • So f(x)=1x−2 has domain x not equal to 2, and g(x) = the square root of (x−3) has domain x≥3
  • The range comes from the outputs: a square is never negative, so x2+1 has range f(x)≥1
  • The domain is written as an inequality in x, and the range as an inequality in f(x).

Inputs a rule cannot use

The domain is the set of inputs a function may take. A denominator cannot be 0, so that input is excluded.

A root needs zero or more

A square root cannot take a negative number. So x+1 needs x+1≥0, giving x≥−1

Learn

Read each card, then follow the worked examples one step at a time.

A square is never negative

The range is the set of outputs a function gives. Since x2≥0, x2−4 gives f(x)≥−4

Build from the smallest output

Start from the smallest value of the square or the root. Then follow it through the rule.
