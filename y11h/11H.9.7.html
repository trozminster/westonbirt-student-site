Topic 11H.9 · Functions and Graph Transformations · Lesson 7 of 11

Harder Inverse Functions

Some rules hide x in two places, so no single run backwards through the steps will undo them. Today's inverses use the subject-twice method, and inverses turn into a quick way to solve equations.

By the end you’ll know…
  • When x appears twice in y = f(x), as in y = 2x + 1x - 3, the denominator is cleared, the x terms are collected on one side and x is factorised out, as in changing the subject.
  • The domain of f⁻¹ is the range of f, and the range of f⁻¹ is the domain of f.
  • A function has an inverse only when each output comes from one input, so a quadratic needs a limited domain, such as x >= 0, first.
  • An equation such as f⁻¹(x) = 4 is solved most simply as x = f(4).
By the end you can
G8Find the inverse of a function where x appears twice, such as f(x) = 2x + 1x - 3, by collecting the x terms and factorising.

Learn

Read each card, then follow the worked examples one step at a time.

x in two places

When x appears twice, the x terms are collected on one side. Then x is factorised out and freed by dividing.

Domain and range swap

The inverse swaps every input with its output. So the domain of f⁻¹ is the range of f.

WORKED EXAMPLE A
f(x) = 3x + 2x - 1. Find f⁻¹(x).
Clear the fractionxy - y = 3x + 2
Collect, then factorisex(y - 3) = y + 2
f⁻¹(x) = x + 2x - 3
WORKED EXAMPLE B
f(x) = x² + 1 for x ≥ 0. Find f⁻¹(x) and its domain.
Make x the subjectx = √(y - 1)
f⁻¹(x) = √(x - 1)
Domain of the inversex ≥ 1 The range of f is f(x) ≥ 1, so that is the domain of the inverse
the positive root is taken because x ≥ 0.

05

Learn

Read each card, then follow the worked examples one step at a time.

Use f, not the inverse

If f⁻¹(x) = 4, then x is the output of f at 4. So x = f(4), with no inverse needed.

Inverses inside equations

An equation can mix inverses and composites. Each expression is found first, then the equation is solved.

WORKED EXAMPLE C
f(x) = x + 72. Solve f⁻¹(x) = 5.
Apply f to 5x = 5 + 72
x = 6
WORKED EXAMPLE D
f(x) = 4x - 3 and g(x) = x + 6. Solve f⁻¹(x) = g(x).
Find the inversef⁻¹(x) = x + 34
Set the two equalx + 34 = x + 6
x + 3 = 4x + 24
x = -7
YOUR TURN · c
f(x) = 2x² + 1 for x ≥ 0. Solve f⁻¹(x) = 3.
x = f(3) = 19
YOUR TURN · d
f(x) = 3x + 2 and g(x) = x - 2. Solve fg(x) = f⁻¹(x).
3x - 4 = x - 23, so 9x - 12 = x - 2; x = 1.25
