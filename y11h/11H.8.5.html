Midpoints and Ratios on Lines

A point halfway along a line, or a third of the way, is still reached by a route of known vectors. Today we find vectors to midpoints and to points that split a line in a ratio.

By the end you’ll know…
  • If M is the midpoint of AB, then vector AM=12 vector AB.
  • If P divides AB in the ratio m:n, then vector AP=mm+n of vector AB, because the line is split into m+n equal parts.
  • The vector to such a point from O is found by a route: vector OP = vector OA + vector AP.
  • With vector OA=a and vector OB=b, vector AB=b−a, so vector OM =a +12(b−a) =12(a+b).

Learn

Halfway along

The midpoint M is halfway along AB, in the same direction. So AM→ is half of AB→.

Start the route at O

To reach M from O, go to A first, then halfway along AB. So OM→ = a+12(b−a) =12(a+b).

WORKED EXAMPLE A
OA→ = a, OB→ = b and M is the midpoint of AB. Find OM→.
Find AB→ firstAB→=b−a

OM→=12(a+b)

Learn

Read each card, then follow the worked examples one step at a time.

A ratio cuts equal parts

A ratio m : n cuts a line into m+n equal parts. So AP : PB=1 : 3 puts P a quarter along.

The same fraction of the vector

The same fraction applies to the vector. So AP→ = ¹⁄₄AB→, and OP→ = a +14(b−a).

WORKED EXAMPLE C
