Equations of Tangents

A tangent is a straight line, so it has an equation like any other. Differentiation supplies its gradient, and the point it touches supplies the rest.

By the end you’ll know…
  • The tangent at a point has the same gradient as the curve there, so m is found by substituting the x-value into dydx.
  • The tangent passes through the point itself, so substituting the point into y = mx + c gives c.
  • When only x is given, the y-coordinate of the point is found from the equation of the curve first.
  • The point where the gradient takes a given value is found by setting dydx equal to that value and solving; a tangent parallel to a line has that line's gradient.
By the end you can
G8Find the equation of the tangent to a curve at a given point.
G9Find the point or points on a curve where the gradient takes a given value, including where a tangent is parallel to a given line.

The tangent's gradient is dydx at the point. The tangent also passes through the point.

The tangent at a point has the same gradient as the curve there, found from dydx. It also passes through the point itself.

Learn

Work backwards from a gradient

Where the gradient has a value, dydx equals it. On y = x², gradient 6 means 2x = 6, so x = 3.

To find where the gradient has a given value, dydx is set equal to it and solved for x. On y = x², the gradient is 6 where 2x = 6, at x = 3.

A gradient can occur twice

A cubic's dydx is a quadratic, so a gradient can occur twice. Each x needs its own y.

A cubic's gradient function is a quadratic, so the same gradient can occur at two points. Each x-value then needs its own y-coordinate.
