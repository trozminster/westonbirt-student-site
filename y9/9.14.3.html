Topic 9.14 · Simultaneous Equations and Graphs · Lesson 3 of 9

Elimination: Same Coefficients

Adding two true statements together, or subtracting one from the other, gives another true statement. Today is about using that fact to knock one unknown out of a pair of equations altogether.

By the end you’ll know…
  • Adding or subtracting two true equations produces a third equation that is also true.
  • If a variable has the same coefficient in both, subtracting removes it; if the coefficients are equal but opposite, adding removes it.
  • Removing one variable leaves a single equation in the other, which solves as usual.
  • The value found is substituted back into either original equation to give the second unknown.
  • Same signs subtract, different signs add.

A third true equation

Adding or subtracting two true equations gives another true equation. Matching coefficients with the same sign: subtract. Equal but opposite coefficients: add.

Adding or subtracting two true equations produces a third equation that is also true. If a variable's coefficient is the same in both, subtracting it removes it; if the coefficients are equal but opposite, adding removes it.

Same signs subtract, different signs add

Removing one variable leaves a single equation in the other, solved as usual. The value found is substituted back into either original equation to give the second unknown.

Deciding add or subtract

Add or subtract depending only on the signs of the matching coefficients. Same signs subtract, different signs add.

Whether to add or subtract depends only on the signs of the coefficients being eliminated, never on which variable "looks easier". Same signs subtract, different signs add.

Matching sizes first

Elimination works directly only when coefficients match in size. Otherwise scale an equation first, next lesson's method.

Elimination only works directly when a variable's coefficients already match in size. If they do not, at least one equation must be scaled first, which is next lesson's method.

In the pair 5x+y=12 and 5x+3y=20, should you add or subtract to eliminate x, and why?

3
Explain why adding two true equations together produces another true equation.
Each side of an equation is an equal quantity to the other, so adding equal quantities to equal quantities keeps the two new totals equal.
