Topic 9.16 · Combined Events and Tree Diagrams · Lesson 4 of 9

Tree Diagrams

A tree diagram lays out every possible outcome of a sequence of events as branches, so nothing gets missed. Today is about building one correctly and reading combined probabilities from it.

By the end you’ll know…
  • A tree diagram lists every possible outcome of a sequence of events, one branch per outcome.
  • The probabilities on any one set of branches sum to 1
  • Probabilities multiply along a path, because a path is an 'and'.
  • Probabilities add across paths, because separate paths are an 'or'.
  • All the final path probabilities together sum to 1, which checks the diagram.
By the end you can
G5Draw a tree diagram for two events and label every branch probability.
G5Find the probability of combined outcomes from a tree diagram.

What a tree records

A tree diagram shows every outcome of a sequence of events. Each set of branches sums to 1

A tree diagram lists every possible outcome of a sequence of events, one branch per outcome. The probabilities on any one set of branches sum to 1

Multiply along, add across

Multiply along a path: a path is an and. Add across paths: separate paths are an or.

Probabilities multiply along a path, because a path is an "and". Probabilities add across paths, because separate paths are an "or". All the final path probabilities together sum to 1, which checks the diagram.

Checking the diagram

All the final path probabilities sum to 1
If not, a branch or a product has gone wrong.

All the final path probabilities together sum to 1
If they do not, a branch probability or a multiplication has gone wrong somewhere in the tree.

Choosing which paths to add

"At least one" or "exactly one" usually needs several paths added. The question decides which paths qualify. e.g. exactly one wet day: 0.21+0.21=0.42

A question asking for "at least one" or "exactly one" outcome usually needs more than one path added together. Reading the question carefully decides which paths qualify.
