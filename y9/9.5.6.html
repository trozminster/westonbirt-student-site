Topic 9.5 · Reverse Percentages and Compound Interest · Lesson 6 of 7

Depreciation and Mixed Rates

Compound growth assumes the same rate every period, but real rates often change - a savings account's interest rate is adjusted, or an asset's value drops by a different percentage each year. This lesson extends the compound formula to handle changing rates, then applies the whole idea to depreciation - value that shrinks each period - including working out how many periods it takes to fall below a target value.

By the end you’ll know…
  • Depreciation is repeated percentage decrease, so its multiplier is below 1
  • After n periods the value is the original x multiplierⁿ, exactly as for growth.
  • Where the rate differs between periods, the multipliers are multiplied in sequence rather than raised to a power.
  • The number of periods needed to reach a given value is found by applying the multiplier repeatedly and counting.

When the rate differs between periods, multiply in sequence

The power shortcut needs the same rate every period. When the rates differ, multiply each period's multiplier in turn.

The power shortcut (multiplierⁿ) only works when every period uses the SAME rate. When the rate changes from period to period, each period needs its own multiplier, and the multipliers are multiplied together in sequence - exactly as with successive percentage changes in Lesson 9.5.2 - rather than any single multiplier being raised to a power. For three years at three different rates, the calculation is original × multiplier1 × multiplier2 × multiplier3, in the order the rates occurred.

Building each period's multiplier separately

Build each period's multiplier from its own rate. A rise gives a multiplier above 1
A fall gives one below 1

Before multiplying, build every period's multiplier individually from its own rate, taking care with the direction of each one (increase gives a multiplier above 1, decrease gives one below 1) - a mixed-rate problem often combines rises and falls in the same sequence, so treat each period's multiplier as its own small percentage-multiplier problem from Lesson 9.5.1 before combining them.

Learn

Read each card, then follow the worked examples one step at a time.

Depreciation is repeated percentage decrease

Depreciation is a repeated decrease at the same rate. Value = original × multiplierⁿ, with the multiplier below 1

Depreciation describes value falling by the same percentage each period - a car, a laptop, or machinery losing value year after year. Because it's a repeated decrease at the same rate, it uses exactly the compound formula from Lesson 9.5.5, except the multiplier is below 1(1 - rate) rather than above 1: after n periods, value = original × multiplierⁿ. The value shrinks by a smaller absolute amount each period, since each period's decrease is calculated on a running total that is itself getting smaller.

Finding how many periods are needed

Apply the multiplier once per period. Count the periods until the value first passes the target. e.g. 5000×0.8 each period, target 2500

Some problems ask the reverse question: not "what's the value after n periods", but "after how many periods does the value first fall to (or below) a target?" Since there's no simple formula to jump straight to the answer, apply the multiplier repeatedly - once per period - and count how many applications it takes to reach or pass the target, checking the running value against the target after each one.
