Topic 9.2 · Linear Graphs and y = mx + c · Lesson 3 of 7

Drawing Linear Graphs

A table of values is only useful once it becomes an accurate picture - a graph drawn on a badly-chosen scale is as unreliable as no graph at all. Today you'll learn to turn a table into an accurate, readable graph, and to read values back off it with confidence.

By the end you’ll know…
  • Every point on a line satisfies its equation, so the graph is the set of all its solutions.
  • A point not on the line does not satisfy the equation, which is how a plotting error shows itself.
  • The axes need a scale going up in equal steps, chosen to fit the range of values in the table.
  • Reading up from a given x to the line and then across gives the matching y, and the reverse gives x from y.
  • A value read off a graph is only as accurate as the scale allows.
By the end you can
G4Draw linear graphs accurately, choosing a suitable scale for the axes.
G4Use a graph to find y for a given x and x for a given y.

Every point on the line

Every point on the line satisfies its equation. A plotted point off the line signals an error.

Every point that lies on a straight line's graph satisfies that line's equation - the graph is the complete picture of every solution to the equation. A plotted point that does NOT lie on the line therefore signals an error somewhere in the working, not a valid extra point.

Choosing the scale

Choose a scale with equal steps that fits the whole table. The graph should fill the grid without running off it.

Before plotting, the axes need a scale that goes up in equal steps and fits the full range of values in the table, so the graph uses the space available without running off the edge or leaving most of the grid empty.

Learn

Read each card, then follow the worked examples one step at a time.

The graph as a lookup table

The graph works as a lookup table between x and y. For y, read up to the line, then across. For x, read across, then down.

Because every point on the line satisfies the equation, the graph itself works as a lookup table between x and y: y for a given x is found by reading up from that x-value on the horizontal axis until you reach the line, then across to the y-axis. To find x for a given y, do the reverse: read across from that y-value until you reach the line, then read down to the x-axis.

Accuracy and the scale

A reading is only as accurate as the scale. Between grid lines, read the actual position, not the nearest line.

A value read off a graph is only as accurate as the scale allows - if a point falls between two grid lines, the read-off value should reflect its actual position between them, not just be rounded to the nearest line.
