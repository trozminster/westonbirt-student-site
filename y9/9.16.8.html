Continuous Data and Conditional

Continuous data can take any value in a range, so its classes are written differently – and a conditional probability restricts attention to only the outcomes where something is already known. Today covers both.

By the end you’ll know…
  • Continuous data can take any value in a range, so its classes are written as inequalities.
  • Inequality boundaries leave no gaps, so every value falls into exactly one class.
  • The midpoint of a class is halfway between its two boundaries.
  • A conditional probability restricts the sample space to the outcomes where a known event has already happened.
  • On a tree diagram that means using only the branches following the known outcome, rescaled so they sum to 1.

Continuous classes

Continuous classes are written as inequalities, with no gaps. Every value falls into exactly one class. A class midpoint is halfway between its boundaries.

Continuous data can take any value in a range, so its classes are written as inequalities. Inequality boundaries leave no gaps, so every value falls into exactly one class. The midpoint of a class is halfway between its two boundaries.

Conditional probability

A conditional probability only uses outcomes where the known event happened. Those outcomes become the whole sample space. e.g. P(cat given boy) = 610.

A conditional probability restricts the sample space to the outcomes where a known event has already happened. On a tree diagram that means using only the branches following the known outcome, rescaled so they sum to 1.

Reading a conditional tree

On a tree, use only the branches after the known outcome. Treat them as the whole sample space.

On a tree diagram, a conditional probability restricts attention to the branches following the known outcome. Those branches are then treated as the whole sample space, rescaled to sum to 1.

Direction matters

P(A given B) looks only where B has happened. P(B given A) is a different question.

P(A given B) restricts to the branches where B has already happened, and asks about A within them. This is not the same question as P(B given A), which restricts to A's branches instead.
