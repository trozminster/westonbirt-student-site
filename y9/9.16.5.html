Topic 9.16 · Combined Events and Tree Diagrams · Lesson 5 of 9

Dependent Events

Without replacement, the first outcome changes what is left for the second draw. Today is about tracking that change correctly on a tree diagram.

By the end you’ll know…
  • With no replacement the first outcome changes what is left, so the second set of branch probabilities differs.
  • Both the numerator and the denominator change: one fewer of the item taken, and one fewer in total.
  • Each second-stage branch set has its own probabilities, depending on which first branch it follows.
  • Each branch set still sums to 1, which is the check that the diagram is right.

Solving problems from a tree

Once the tree is labelled, the and/or rules apply as before. Multiply along a path, then add qualifying paths.

Once a dependent tree is fully labelled, the and/or rules from earlier lessons apply exactly as before – multiply along a path, add across qualifying paths.

Checking the tree

Check that each branch set sums to 1
If one doesn't, a probability was carried over wrongly.

A quick check is that each branch set – the first pair, and each second pair – sums to 1
If a set does not sum to 1, a probability was carried over incorrectly from the first draw.
