Topic 9.15 · Ratio, Scales and Proportion · Lesson 3 of 6

Map Scales and Drawings

A map shrinks a real place down onto a page while keeping its shape exact. Today is about the ratio that links a map to reality, and using it in both directions.

By the end you’ll know…
  • A map scale is a ratio of distance on the map to the matching real distance.
  • Both parts must be in the same unit before the scale is used.
  • A scale written 1:n means one unit on the map represents n of the same units in reality.
  • Map to real multiplies by the scale, and real to map divides by it.
  • A scale drawing preserves angles and shape, so only the lengths change.

What a scale means

A map scale is the ratio of map distance to real distance. Both parts must be in the same unit. 1:n means 1 map unit is n real units.

A map scale is a ratio of distance on the map to the matching real distance. Both parts must be in the same unit before the scale is used. A scale written 1:n means one unit on the map represents n of the same units in reality.

Two directions

Map to real multiplies by the scale, and real to map divides by it. A scale drawing preserves angles and shape, so only the lengths change.

Producing a scale drawing

A scale drawing changes every length by the same factor. Every angle stays the same. Choose a scale that fits the page first.

A scale drawing shrinks or enlarges every length by the same factor while keeping every angle the same. Choosing a sensible scale first makes the real lengths convert to a page-sized drawing.

Reading and building drawings

Interpreting a scale drawing means measuring a length on it and scaling up. Producing one means scaling every real length down by the same factor before drawing.
