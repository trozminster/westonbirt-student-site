Upper and Lower Bounds

A length given as 24 cm to the nearest centimetre could really be anything from 23.5 cm up to, but not including, 24.5 cm. Today pins down exactly where the true value can lie.

By the end you’ll know…
  • A rounded value stands for an interval of possible true values, not a single one.
  • The bounds lie half a rounding unit either side, so 24 to the nearest whole number has bounds 23.5 and 24.5
  • The lower bound is included and the upper bound excluded, since 24.5 would itself round up.
  • The interval is written as an error interval in inequality notation: 23.5≤x<24.5
  • The rounding unit sets the half: to the nearest 10 the bounds are 5 either side, and to 1 decimal place 0.05

A rounded value is an interval

A rounded value stands for every value that rounds to it. The bounds lie half a rounding unit either side.

Half of which unit

The rounding unit sets the half. To the nearest 10 it is 5, and to 1 decimal place it is 0.05

WORKED EXAMPLE A
A length is 24 cm to the nearest cm. Find its bounds.
Halve the unit1÷2=0.5
Lower bound24−0.5=23.5 cm
Upper bound24+0.5=24.5 cm

Writing the interval

The error interval is written lower bound ≤ x < upper bound. The lower bound is included and the upper bound is not.

Why the upper bound is left out

The upper bound itself rounds up to the next value. So x never equals the upper bound.

The upper bound itself rounds up to the next value. So x can be as close to it as you like, but not equal to it.
