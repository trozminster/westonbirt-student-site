Coordinates and Gradients

Every map reference, sports pitch marking and computer game position relies on coordinates to pin down an exact spot - and every ramp, roof and road sign relies on gradient to describe how steep it is. Today you'll learn to read and plot coordinates anywhere on a grid, and to measure exactly how steep a line is.

By the end you’ll know…
  • A coordinate pair gives horizontal position then vertical position, (x, y), across all four quadrants.
  • A vertical line has equation x=a and a horizontal line y=b.
  • Gradient measures steepness: the vertical change divided by the horizontal change.
  • A positive gradient rises from left to right and a negative gradient falls.
  • The gradient of a straight line is the same wherever along it it is measured.

Learn

Reading a coordinate pair

A coordinate pair (x, y) gives the horizontal position first. Go along first, then up.

A coordinate pair (x, y) always gives the horizontal position first, then the vertical position: how far along, then how far up.

The four quadrants

The axes split the grid into four quadrants at the origin (0,0). The signs of the coordinates show the quadrant.

The grid is divided into four quadrants by the x-axis and y-axis crossing at the origin (0,0). The sign of each coordinate tells you which quadrant a point is in: (+,+) top right, (-,+) top left, (-,-) bottom left, (+,-) bottom right.

Vertical and horizontal lines

Every point on a vertical line shares its x-coordinate: x = a. Every point on a horizontal line shares its y-coordinate: y=b.

A vertical line has every point sharing the same x-coordinate, so its equation is x = a for some number a. A horizontal line has every point sharing the same y-coordinate, so its equation is y=b for some number b.

Learn

Read each card, then follow the worked examples one step at a time.

What gradient measures

Gradient measures how steep a line is. Gradient = vertical change / horizontal change.

Gradient measures how steep a line is: the amount the line rises or falls (vertical change) for every unit moved across (horizontal change). Gradient = vertical change / horizontal change.

Positive and negative gradients

A positive gradient rises from left to right. A negative gradient falls from left to right.

A line with a positive gradient rises from left to right; a line with a negative gradient falls from left to right.

The same all along the line

A straight line's gradient is the same wherever it is measured. Any two points on it give the same value.

The gradient of a straight line is the same number wherever along the line it is measured - any two points on the same straight line give the same value.
