Averages from Grouped Data

When data is grouped into classes, the individual values are lost – only which class each fell into is known. Today is about estimating an average anyway, using each class's midpoint to stand in for its values.

By the end you’ll know…
  • Grouping data loses the individual values, so only the class each value fell into is known.
  • The mean can therefore only be estimated, using each class midpoint to stand in for its values.
  • The estimated mean is the total of midpoint x frequency, divided by the total frequency.
  • The modal class is the class with the highest frequency, and the median is the class containing the middle value.
  • Both are classes rather than single values, which is why they are named rather than calculated.

Why only an estimate

The three averages

Finding the median class

Find the n+12 th position, as for any median. Report the class containing it, not a value.

The median class is found the same way as an ungrouped median – locate the n+12 th position – but reported as the class containing that position, since the exact value inside is unknown.

Putting it together

One table gives the estimated mean, modal class and median class. Each has its own method.

A full grouped-data question usually asks for the estimated mean, the modal class, and the median class together, each found by its own method but from the same table.
